Propiedad border-radius

La propiedad border-radius de CSS se utiliza para redondear las esquinas del borde exterior de un elemento. Esta propiedad es muy útil para crear diseños más suaves y visualmente atractivos.

Sintaxis básica y ejemplos

Aplicar un radio de 10px a todas las esquinas:

border-radius: 10px;

Aplicar 10px a las esquinas superior izquierda e inferior derecha, y 20px a las esquinas superior derecha e inferior izquierda:

border-radius: 10px 20px;

Aplicar diferentes radios a cada esquina en el orden: superior izquierda, superior derecha, inferior derecha, inferior izquierda:

border-radius: 10px 20px 30px 40px;

Podemos crear esquinas elípticas utilizando dos valores separados por una barra /:

Aplicar un radio horizontal de 10px y un radio vertical de 20px a todas las esquinas:

border-radius: 10px / 20px;

Aplicar diferentes radios horizontales y verticales a cada esquina:

border-radius: 10px 20px / 30px 40px;

También podemos especificar cada esquina individualmente:

border-top-left-radius: 10px;

border-top-right-radius: 20px;

border-bottom-right-radius: 30px;

border-bottom-left-radius: 40px;

Ejemplos prácticos

Esquinas redondeadas uniformemente:

.rounded-box {
  border: 2px solid #000;
  border-radius: 15px;
}

Esquinas elípticas:

.elliptical-box {
  border: 2px solid #000;
  border-radius: 15px 50px;
}
