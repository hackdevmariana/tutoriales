Propiedad border

La propiedad border de CSS es una propiedad abreviada que permite definir el estilo, el ancho y el color del borde de un elemento en una sola declaración.

Sintaxis básica

Ancho de 1px, estilo sólido, color negro:

.box{
  border: 1px solid #000;
}

Componentes de la propiedad border

  • border-width: Define el grosor del borde. Puede ser un valor en píxeles, em, rem, etc.

Ejemplo:

.box{
  border-width: 2px;
}

  • border-style: Define el estilo del borde. Los valores posibles incluyen:

  • none: Sin borde.

  • solid: Borde sólido.

  • dotted: Borde punteado.

  • dashed: Borde discontinuo.

  • double: Borde doble.

  • groove: Borde con efecto de surco.

  • ridge: Borde con efecto de cresta.

  • inset: Borde con efecto de inserción.

  • outset: Borde con efecto de salida.

Ejemplo:

.box{
  border-style: solid;
}
  • border-color: Define el color del borde. Puede ser un valor en nombre de color, hexadecimal, RGB, RGBA, HSL, HSLA, etc.

Ejemplo:

.box{
  border-color: #ff0000;
}

Propiedades individuales

Podemos definir cada lado del borde por separado utilizando las propiedades border-top, border-right, border-bottom y border-left:

Ejemplo:

.box{
  border-top: 2px solid #000;
  border-right: 2px dashed #ff0000;
  border-bottom: 2px dotted #00ff00;
  border-left: 2px double #0000ff;
}

Ejemplos prácticos

Borde de 3px con efecto de cresta y color rojo oscuro


.box {
border: 3px ridge #8b0000;
}

Borde de 2px discontinuo y color naranja:


.highlight {
border: 2px dashed #ffa500; 
}
