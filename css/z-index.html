Propiedad z-index

La propiedad z-index en CSS se utiliza para controlar el orden de apilamiento de los elementos posicionados en una página web. Esto es especialmente útil cuando tenemos elementos que se superponen y necesitamos definir cuál debe estar encima de los demás.

Conceptos clave

Posicionamiento: La propiedad z-index solo funciona en elementos que tienen una posición distinta de static (es decir, relative, absolute, fixed o sticky).

Valores: El valor de z-index puede ser un número entero positivo o negativo. Los elementos con un valor de z-index más alto se apilan por encima de los elementos con un valor más bajo.

Contexto de apilamiento: Un nuevo contexto de apilamiento se crea en ciertos casos, como cuando un elemento tiene una posición distinta de static y un valor de z-index establecido. Los elementos dentro de este contexto se apilan en relación con ese contexto, no con el resto de la página.

Ejemplo básico

<div class="box1">Box 1</div>
<div class="box2">Box 2</div>
<div class="box3">Box 3</div>

.box1 {
  position: relative;
  z-index: 1;
  background-color: red;
  width: 100px;
  height: 100px;
}
.box2 {
  position: absolute;
  z-index: 2;
  background-color: green;
  width: 100px;
  height: 100px;
  top: 50px;
  left: 50px;
}
.box3 {
  position: absolute;
  z-index: 3;
  background-color: blue;
  width: 100px;
  height: 100px;
  top: 100px;
  left: 100px;
}

En este ejemplo, box3 se apilará por encima de box2, y box2 se apilará por encima de box1 debido a sus valores de z-index.
