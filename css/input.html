Cambiar el estilo de un input con CSS

En CSS, podemos personalizar los campos de entrada (input) de muchas maneras para mejorar la apariencia y la funcionalidad de tus formularios web.

Veamos algunas de las propiedades más comunes que podemos usar:

border: Controla el estilo, el grosor y el color del borde del campo de texto.

input {
  border: 2px solid #000;
}

background-color: Cambia el color de fondo del campo de entrada.

input {
  background-color: #f0f0f0;
}

color: Cambia el color del texto dentro del campo de entrada.

input {
  color: #333;
}

padding: Ajusta el espacio interior del campo de entrada.

input {
  padding: 10px;
}

font-size: Cambia el tamaño de la fuente del texto dentro del campo de entrada.

input {
  font-size: 16px;
}

box-shadow: Añade sombras al campo de entrada para darle un efecto de profundidad.

input {
  box-shadow: 2px 2px 5px rgba(0, 0, 0, 0.3);
}

width y height: Ajusta el ancho y el alto del campo de entrada.

input {
  width: 100%;
  height: 40px;
}

border-radius: Redondea las esquinas del campo de entrada.

input {
  border-radius: 5px;
}
