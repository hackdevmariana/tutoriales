Pseudo-elemento ::after

El pseudo-elemento ::after en CSS se utiliza para insertar contenido después del contenido de un elemento seleccionado. Este contenido se define mediante la propiedad content.

Sintaxis básica

selector::after {
  content: "texto o contenido";
}

Ejemplo simple

p::after {
  content: " - Recuerda esto";
}

En este ejemplo, se añade el texto " - Recuerda esto" después del contenido de cada elemento <p>.

Usos comunes

  • Añadir decoraciones: podemos usar ::after para añadir iconos, flechas, o cualquier otro contenido decorativo.
a::after {
  content: "→";
}
  • Tooltips: crear tooltips que aparecen al pasar el ratón sobre un elemento.
span[data-descr]:hover::after {
  content: attr(data-descr);
  position: absolute;
  background-color: #ffffcc;
  padding: 5px;
  border: 1px solid #aaaaaa;
}
