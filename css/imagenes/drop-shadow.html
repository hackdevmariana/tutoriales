Aplicar una sombra paralela a una imagen con el filtro drop-shadow

El filtro drop-shadow en CSS se utiliza para aplicar una sombra a un elemento, similar a la propiedad box-shadow, pero con algunas diferencias clave. Este filtro es parte de la propiedad filter, que permite aplicar varios efectos gráficos a elementos HTML.

Uso básico

La sintaxis básica para usar filter: drop-shadow es:

element {
  filter: drop-shadow(<offset-x> <offset-y> <blur-radius> <color>);
}

Parámetros

  • offset-x: Desplazamiento horizontal de la sombra.

  • offset-y: Desplazamiento vertical de la sombra.

  • blur-radius: Radio de desenfoque de la sombra.

  • color: Color de la sombra.

Ejemplo práctico

.drop-shadow {
  filter: drop-shadow(10px 10px 5px rgba(0, 0, 0, 0.5));
}

En este ejemplo:

  • La clase drop-shadow aplica una sombra con un desplazamiento de 10 píxeles en ambas direcciones (horizontal y vertical), un radio de desenfoque de 5 píxeles y un color negro con una opacidad del 50%.

Diferencias con box-shadow

  • drop-shadow: Se aplica como un filtro y puede afectar a elementos con bordes no rectangulares, como imágenes con bordes redondeados o elementos SVG.

  • box-shadow: Se aplica directamente a la caja del elemento y no afecta a los bordes no rectangulares.
