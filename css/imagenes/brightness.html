Cambiar el brillo en una imagen con CSS

El filtro brightness en CSS se utiliza para ajustar el brillo de un elemento. Este filtro es parte de la propiedad filter, que permite aplicar varios efectos gráficos a elementos HTML.

Uso básico

La sintaxis básica para usar filter: brightness es:

element {
  filter: brightness(<valor>);
}

El valor puede ser un número o un porcentaje:

  • 1 o 100%: No cambia el brillo.

  • Valores menores que 1: Disminuyen el brillo (hacen el elemento más oscuro).

  • Valores mayores que 1: Aumentan el brillo (hacen el elemento más claro).

Ejemplo práctico

.high-brightness {
  filter: brightness(150%);
}
.low-brightness {
  filter: brightness(50%);
}

En este ejemplo:

  • La clase high-brightness aplica un brillo del 150%, haciendo que la imagen sea más clara.

  • La clase low-brightness aplica un brillo del 50%, haciendo que la imagen sea más oscura.
