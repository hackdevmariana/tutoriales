Efectos sobre imágenes en CSS

Los efectos de imágenes en CSS permiten mostrar las imágenes de manera dinámica en una página web sin modificar la imagen original.

Hay varias formas de modificar las imágenes con CSS:

Filtros

Los filtros en CSS se utilizan para aplicar efectos gráficos como desenfoque, brillo, contraste, etc., a una imagen.

Ejemplos:

Convertir la imagen a escala de grises:

img {
  filter: grayscale(100%);
}

Aplicar un efecto sepia a la imagen:

img {
  filter: sepia(100%);
}

Desenfocar la imagen:

img {
  filter: blur(5px);
}

Aumentar el brillo de la imagen:

img {
  filter: brightness(150%);
}

Aumentar el contraste de la imagen:

img {
  filter: contrast(200%);
}

Transiciones

Las transiciones en CSS permiten cambiar gradualmente de un estilo a otro cuando ocurre un evento, como pasar el cursor sobre la imagen.

Aumentar el tamaño de la imagen al pasar el cursor por encima:

img {
  transition: transform 0.5s ease-in-out;
}

img:hover {
  transform: scale(1.2);
}

Transformaciones

Las transformaciones en CSS permiten rotar, escalar, inclinar, o mover imágenes.

Rotar la imagen 45 grados:

img {
  transform: rotate(45deg);
}

Escalar la imagen al 150% de su tamaño original:

img {
  transform: scale(1.5);
}

Mover la imagen 50 píxeles a la derecha:

img {
  transform: translateX(50px);
}

Sombras

Las sombras en CSS se utilizan para agregar sombra alrededor de las imágenes, lo que puede dar un efecto de profundidad.

Agregar una sombra alrededor de la imagen:

img {
  box-shadow: 10px 10px 5px #888888;
}

Máscaras

Las máscaras en CSS permiten mostrar partes específicas de una imagen usando formas o imágenes de máscara.

img {
  mask-image: url('mask.png');
  mask-mode: alpha;
}

Blend Modes

Los modos de mezcla en CSS permiten combinar la imagen con su fondo para crear nuevos efectos.

img {
  mix-blend-mode: multiply;
}
