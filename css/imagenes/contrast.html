Cambiar el contraste en una imagen con el filtro filter:contrast

El filtro contrast en CSS se utiliza para ajustar el contraste de un elemento. Este filtro es parte de la propiedad filter, que permite aplicar varios efectos gráficos a elementos HTML.

Ejemplo básico

La sintaxis básica para usar filter: contrast es:

element {
  filter: contrast(<valor>);
}

El valor puede ser un número o un porcentaje:

  • 1 o 100%: No cambia el contraste.

  • Valores menores que 1: Disminuyen el contraste.

  • Valores mayores que 1: Aumentan el contraste.

Ejemplo práctico

.high-contrast {
  filter: contrast(200%);
}
.low-contrast {
  filter: contrast(50%);
}

En este ejemplo:

  • La clase high-contrast aplica un contraste del 200%, haciendo que los colores sean más intensos.

  • La clase low-contrast aplica un contraste del 50%, haciendo que los colores sean más apagados.
