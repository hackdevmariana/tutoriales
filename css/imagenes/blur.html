Mostrar una imagen desenfocada

El filtro blur en CSS se utiliza para aplicar un efecto de desenfoque a un elemento. Este filtro es parte de la propiedad filter, que permite aplicar varios efectos gráficos como desenfoque, brillo, contraste, entre otros, a elementos HTML.

Ejemplo básico

img {
  filter: blur(5px);
}

En este ejemplo, cualquier imagen (img) en la página tendrá un desenfoque de 5 píxeles.

El valor puede ser cualquier longitud (por ejemplo, px, em). Un valor mayor produce un mayor desenfoque.

Animación con filter:blur

Podemos crear una animación con filter:blur en CSS utilizando la regla @keyframes para definir los estados de la animación y la propiedad animation para aplicarla a un elemento:

.blur-animation {
  width: 200px;
  height: 200px;
  background-color: #3498db;
  animation: blurEffect 3s infinite;
}

@keyframes blurEffect {
  0% {
    filter: blur(0);
  }
  50% {
    filter: blur(10px);
  }
  100% {
    filter: blur(0);
  }
}
