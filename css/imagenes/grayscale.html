Mostrar una imagen en blanco y negro con grayscale

La propiedad filter: grayscale en CSS se utiliza para aplicar un efecto de escala de grises a una imagen o a cualquier otro elemento HTML. Este filtro convierte los colores de la imagen en tonos de gris, eliminando la saturación de color.

img {
  filter: grayscale(100%);
}

Valores de grayscale

  • 0%: La imagen se muestra en color completo (sin efecto de escala de grises).

  • 100%: La imagen se muestra completamente en escala de grises.

  • Valores intermedios: Podemos usar cualquier valor entre 0% y 100% para ajustar el nivel de escala de grises. Por ejemplo, 50% aplicará un efecto de escala de grises parcial.

img {
  filter: grayscale(50%);
}

Ejemplo práctico

Si tenemos una imagen y queremos que se muestre en escala de grises al pasar el ratón por encima, podemos combinar grayscale con la pseudo-clase :hover:

img {
  transition: filter 0.3s ease;
}

img:hover {
  filter: grayscale(100%);
}

En este ejemplo, la imagen se convertirá en escala de grises cuando el usuario pase el ratón por encima, creando un efecto visual interesante.
