Propiedad list-style-type en CSS

La propiedad list-style-type es una propiedad de CSS que se utiliza para especificar el tipo de marcador (bullet) o numeración que se debe usar en los elementos de lista (<ul>, <ol>, y <li>). Esta propiedad permite personalizar la apariencia de las listas, haciéndolas más adecuadas para el diseño de tu página web.

Valores comunes de list-style-type

Para listas desordenadas (<ul>):

  • disc: El valor por defecto. Muestra un círculo sólido.

  • circle: Muestra un círculo hueco.

  • square: Muestra un cuadrado sólido.

  • none: No muestra ningún marcador.

Para listas ordenadas (<ol>):

  • decimal: El valor por defecto. Muestra números (1, 2, 3, ...).

  • decimal-leading-zero: Muestra números con un cero inicial (01, 02, 03, ...).

  • lower-alpha: Muestra letras minúsculas (a, b, c, ...).

  • upper-alpha: Muestra letras mayúsculas (A, B, C, ...).

  • lower-roman: Muestra números romanos en minúsculas (i, ii, iii, ...).

  • upper-roman: Muestra números romanos en mayúsculas (I, II, III, ...).

Ejemplos de uso

Listas desordenadas:

<ul style="list-style-type: circle;">
  <li>Elemento 1</li>
  <li>Elemento 2</li>
  <li>Elemento 3</li>
</ul>

Listas ordenadas:

<ol style="list-style-type: upper-roman;">
  <li>Elemento 1</li>
  <li>Elemento 2</li>
  <li>Elemento 3</li>
</ol>
