Definir todos los estilos de lista en una sola declaración

La propiedad list-style en CSS es una propiedad abreviada que permite definir todos los estilos de lista en una sola declaración. Esta propiedad combina tres propiedades individuales:

  • list-style-type: Define el tipo de marcador de lista (por ejemplo, círculo, cuadrado, número, etc.).

  • list-style-position: Especifica la posición de los marcadores de lista (dentro o fuera del contenido del elemento de la lista).

  • list-style-image: Permite usar una imagen personalizada como marcador de lista.

Ejemplo de uso

ul {
  list-style: square inside url('mi_imagen.png');
}

En este ejemplo:

  • list-style-type: square; define que los marcadores serán cuadrados.

  • list-style-position: inside; coloca los marcadores dentro del contenido del elemento de la lista.

  • list-style-image: url('mi_imagen.png'); usa una imagen personalizada como marcador.

Valores predeterminados

Si no se especifica algún valor, se usarán los valores predeterminados:

  • list-style-type: disc; (círculo relleno).

  • list-style-position: outside; (fuera del contenido del elemento de la lista).

  • list-style-image: none; (sin imagen).
