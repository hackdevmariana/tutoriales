Propiedades de CSS para listas

Las listas en CSS pueden ser estilizadas de diversas maneras para mejorar su apariencia y funcionalidad.

Veamos algunas de las opciones más comunes:

Tipos de listas

Listas no ordenadas (<ul>): Los elementos de la lista están marcados con viñetas.

Listas ordenadas (<ol>): Los elementos de la lista están marcados con números o letras.

Propiedades de CSS para listas

list-style-type: Define el tipo de marcador para los elementos de la lista.

Lista desordenada con un círculo:

ul {
  list-style-type: circle;
}

Lista ordenada con números romanos en mayúsculas:

ol {
  list-style-type: upper-roman;
}

list-style-image: Usa una imagen como marcador de los elementos de la lista.

Ejemplo:

ul {
  list-style-image: url('path/to/image.png');
}

list-style-position: Define la posición del marcador (dentro o fuera del contenido del elemento de la lista).

Dentro del contenido:

ul {
  list-style-position: inside;
}

Fuera del contenido:

ul {
  list-style-position: outside;
}

list-style: Propiedad abreviada para definir list-style-type, list-style-image y list-style-position en una sola declaración.

Ejemplo:

ul {
  list-style: square inside url('path/to/image.png');
}

Eliminar viñetas

Podemos eliminar las viñetas de una lista con list-style-type: none;:

ul {
  list-style-type: none;
  margin: 0;
  padding: 0;
}
