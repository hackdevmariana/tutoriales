Propiedad animation-delay

La propiedad animation-delay en CSS se utiliza para especificar un retraso antes de que comience una animación en un elemento.

La propiedad animation-delay define el tiempo que debe transcurrir desde que se aplica la animación a un elemento hasta que esta comienza.

Podemos especificar el retraso en segundos (s) o milisegundos (ms). Por ejemplo, animation-delay: 2s; retrasará el inicio de la animación 2 segundos.

Si usamos valores negativos, la animación comenzará inmediatamente, pero como si ya hubiera estado en ejecución durante el tiempo negativo especificado. Por ejemplo, animation-delay: -1s; hará que la animación comience desde el segundo 1.

La sintaxis básica es animation-delay: <time>;. Pero podemoss especificar múltiples retrasos separados por comas si tienes varias animaciones aplicadas a un elemento.

Ejemplo

div {
  animation-name: example;
  animation-duration: 4s;
  animation-delay: 2s;
}

@keyframes example {
  from {
    background-color: red;
  }
  to {
    background-color: yellow;
  }
}

En este ejemplo, la animación llamada "example" comenzará 2 segundos después de ser aplicada al elemento div.
