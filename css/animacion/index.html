Animaciones en CSS

Las animaciones en CSS permiten animar la transición entre diferentes estilos de un elemento HTML sin necesidad de usar JavaScript.

El componente @keyframes define los estados de la animación en diferentes puntos del tiempo.

Por ejemplo:

@keyframes ejemplo {
  from { background-color: red; }
  to { background-color: yellow; }
}

Propiedades de animación

Se utilizan para configurar la animación en el elemento HTML. Algunas de las propiedades más comunes son:

  • [animation-name](./animation-name.md): Nombre de la animación definida con @keyframes.

  • [animation-duration](./animation-duration.md): Duración de la animación.

  • [animation-timing-function](./animation-timing-function.md): Define la curva de aceleración de la animación.

  • [animation-delay](./animation-delay.md): Retraso antes de que comience la animación.

  • [animation-iteration-count](./animation-iteration-count.md): Número de veces que se repite la animación.

  • [animation-direction](./animation-direction.md): Dirección de la animación (normal, reverse, alternate, etc.).

Ejemplo básico

Un ejemplo sencillo de una animación que cambia el color de fondo de un div de rojo a amarillo en 4 segundos:

@keyframes cambioColor {
  from { background-color: red; }
  to { background-color: yellow; }
}

div {
  width: 100px;
  height: 100px;
  background-color: red;
  animation-name: cambioColor;
  animation-duration: 4s;
}

Ventajas de las animaciones CSS

  • Facilidad de uso: No hace falta conocimientos avanzados de JavaScript.

  • Rendimiento: Las animaciones CSS son gestionadas por el navegador, lo que permite optimizaciones como el "frame-skipping" para mantener la fluidez.

  • Compatibilidad: Las animaciones CSS son compatibles con la mayoría de los navegadores modernos.
