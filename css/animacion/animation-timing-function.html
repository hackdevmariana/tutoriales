Propiedad animation-timing-function

La propiedad animation-timing-function en CSS define cómo una animación avanza a lo largo de su duración. Específicamente, controla la velocidad de la animación en diferentes puntos, permitiendo que los cambios de estilo sean más suaves o más dramáticos.

La animation-timing-function se aplica entre los keyframes de una animación, no sobre toda la animación.

Valores habituales

  • linear: La animación tiene una velocidad constante de principio a fin.

  • ease: Valor por defecto. La animación comienza lentamente, acelera en el medio y desacelera al final.

  • ease-in: La animación comienza lentamente y luego acelera.

  • ease-out: La animación comienza rápidamente y luego desacelera.

  • ease-in-out: La animación comienza y termina lentamente, con una aceleración en el medio.

  • step-start: La animación salta inmediatamente al estado final al inicio.

  • step-end: La animación salta al estado final al final.

Funciones personalizadas

Podemos definir curvas de velocidad personalizadas usando la función cubic-bezier(n, n, n, n), donde cada parámetro es un número entre 0 y 1 que define la curva de la animación.

Ejemplo

@keyframes example {
  from {
    transform: translateX(0);
  }
  to {
    transform: translateX(100px);
  }
}

div {
  animation-name: example;
  animation-duration: 2s;
  animation-timing-function: ease-in-out;
}

En este ejemplo, el div se moverá 100 píxeles a la derecha en 2 segundos, comenzando y terminando lentamente.
