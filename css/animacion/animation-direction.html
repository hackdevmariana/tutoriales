Propiedad animation-direction en CSS

La propiedad animation-direction en CSS es una propiedad usada dentro de las animaciones y se encarga de especificar en qué dirección se va a ejecutar la animación.

Valores de animation-direction

  • Normal: Esta es la configuración predeterminada. La animación se ejecuta en la secuencia de fotogramas normal, del primero al último.

Ejemplo:

element {
  animation-direction: normal;
}
  • Reverse: La animación se ejecuta en la dirección opuesta, es decir, del último fotograma al primero.
element {
  animation-direction: reverse;
}
  • Alternate: La animación se alterna entre las secuencias de fotogramas normal y reversa. Esto significa que una vez que la animación llega al final de la secuencia, volverá al inicio en la dirección opuesta.
element {
  animation-direction: alternate;
}
  • Alternate-reverse: La animación empieza en la secuencia inversa y luego alterna volviendo a la secuencia normal.
element {
  animation-direction: alternate-reverse;
}

Ejemplo

HTML:

<!DOCTYPE html>
<html lang="es">
<head>
  <meta charset="UTF-8">
  <title>Ejemplo de animation-direction</title>
</head>
<body>
  <div class="animated-box"></div>
</body>
</html>

CSS:

@keyframes example {
  from {background-color: red;}
  to {background-color: yellow;}
}

.animated-box {
  width: 100px;
  height: 100px;
  background-color: red;
  animation-name: example;
  animation-duration: 5s;
  animation-direction: alternate;
}
