Propiedad counter-increment

La propiedad counter-increment en CSS se utiliza para aumentar o disminuir el valor de los contadores CSS. Estos contadores se pueden usar para numerar automáticamente elementos en una página web.

Sintaxis básica

selector {
  counter-increment: nombre-del-contador cantidad;
}

  • nombre-del-contador: El nombre del contador que deseas incrementar.

  • cantidad: La cantidad en la que deseamos incrementar el contador (por defecto es 1).

Ejemplo simple

body {
  counter-reset: seccion;
}
h2::before {
  counter-increment: seccion;
  content: "Sección " counter(seccion) ". ";
}

En este ejemplo, cada elemento <h2> se numera automáticamente como "Sección 1", "Sección 2", etc.

Usos comunes

  • Numeración de secciones: podemos numerar automáticamente secciones y subsecciones en un documento.
body {
  counter-reset: seccion;
}
h1 {
  counter-reset: subseccion;
}
h1::before {
  counter-increment: seccion;
  content: "Sección " counter(seccion) ": ";
}
h2::before {
  counter-increment: subseccion;
  content: counter(seccion) "." counter(subseccion) " ";
}
  • Listas personalizadas: permite crear listas numeradas personalizadas.
ol.custom-list {
  counter-reset: item;
}
ol.custom-list li::before {
  counter-increment: item;
  content: counter(item) ". ";
}
