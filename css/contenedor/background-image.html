Propiedad background-image

La propiedad background-image de CSS se utiliza para establecer una o más imágenes de fondo para un elemento.

Sintaxis

element {
  background-image: url('ruta/a/la/imagen.jpg');
}

Valores

  • url(): Especifica la URL de la imagen. Puedes usar una o varias imágenes separadas por comas.

  • none: No se muestra ninguna imagen de fondo (valor por defecto).

  • gradientes: Puedes usar gradientes como linear-gradient(), radial-gradient(), conic-gradient(), etc.

Ejemplos

Imagen de fondo simple:

body {
  background-image: url('background.jpg');
}

Múltiples imágenes de fondo:

body {
  background-image: url('image1.png'), url('image2.png');
}

Gradiente como fondo:

div {
  background-image: linear-gradient(to right, red, yellow);
}

Comportamiento

  • Repetición: Por defecto, la imagen de fondo se repite tanto horizontal como verticalmente para cubrir todo el elemento.

  • Posicionamiento: Puedes controlar la posición de la imagen de fondo con la propiedad background-position.

  • Tamaño: La propiedad background-size permite ajustar el tamaño de la imagen de fondo.

  • Adjunto: La propiedad background-attachment controla si la imagen de fondo se desplaza con el contenido o permanece fija.
