Propiedad background-position

La propiedad background-position en CSS se utiliza para especificar la posición inicial de una imagen de fondo dentro de su contenedor.

Sintaxis

div {
  background-position: x y;
}

  • x: La posición horizontal (puede ser un valor en píxeles, porcentaje, o palabras clave como left, center, right).

  • y: La posición vertical (puede ser un valor en píxeles, porcentaje, o palabras clave como top, center, bottom).

Ejemplos

Posicionamiento con palabras clave:

.example1 {
  background-image: url('image.jpg');
  background-position: top right;
}

En este caso, la imagen de fondo se coloca en la esquina superior derecha del contenedor.

Posicionamiento con porcentajes:

.example2 {
background-image: url('image.jpg');
background-position: 50% 50%;
}

Aquí, la imagen de fondo se centra tanto horizontal como verticalmente.

Posicionamiento con valores en píxeles:

.example3 {
  background-image: url('image.jpg');
  background-position: 10px 20px;
}

En este ejemplo, la imagen de fondo se coloca a 10 píxeles desde la izquierda y 20 píxeles desde la parte superior del contenedor.

Combinación con otras propiedades

La propiedad background-position se puede combinar con otras propiedades de fondo como background-size, background-repeat, y background-attachment para un control más preciso del fondo.

Ejemplo completo

.example4 {
  background-image: url('image.jpg');
  background-position: center center;
  background-size: cover;
  background-repeat: no-repeat;
  background-attachment: fixed;
}

En este ejemplo, la imagen de fondo se centra, se escala para cubrir todo el contenedor, no se repite y se fija en su posición al hacer scroll.
