Propiedad content

La propiedad content en CSS se utiliza junto con los pseudo-elementos ::before y ::after para generar contenido que se adjunta antes o después de un elemento seleccionado.

Sintaxis

La propiedad content puede tomar varios tipos de valores:

  • Cadena de texto: Añade texto antes o después del elemento.
p::before {
  content: "Nota: ";
}
  • URL: Inserta una imagen o un recurso externo.
p::before {
  content: url('icon.png');
}
  • Atributo: Muestra el valor de un atributo del elemento.
img::after {
  content: attr(alt);
}
  • Contadores: Utiliza contadores CSS para numerar elementos.
h2::before {
  content: counter(chapter) ". ";
}

Ejemplos

Añadir texto antes de un elemento:

h1::before {
  content: "Capítulo: ";
}

Añadir una imagen antes de un párrafo:

p::before {
  content: url('icon.png');
}

Mostrar el valor del atributo alt de una imagen:

img::after {
  content: attr(alt);
}

Usar contadores para numerar secciones:

body {
  counter-reset: section;
}

h2::before {
  counter-increment: section;
  content: "Sección " counter(section) ": ";
}

Consideraciones

  • La propiedad content solo se aplica a los pseudo-elementos ::before y ::after.

  • No se recomienda usar content para añadir contenido significativo, ya que CSS está destinado a la presentación y no a la estructura del documento.

  • La propiedad content es muy útil para mejorar la presentación y la accesibilidad de una página web sin alterar su estructura HTML.
