Propiedad background-clip

La propiedad background-clip en CSS define hasta dónde se extiende el fondo (color o imagen) dentro de un elemento.

Valores posibles

border-box: El fondo se extiende hasta el borde exterior del elemento, incluyendo el borde.

.ejemplo {
  background-clip: border-box;
}

padding-box: El fondo se extiende hasta el borde exterior del padding, pero no se muestra debajo del borde.

.ejemplo {
  background-clip: padding-box;
}

content-box*: El fondo se extiende solo hasta el borde del contenido, excluyendo el padding y el borde.

.ejemplo {
  background-clip: content-box;
}

Ejemplo práctico

.ejemplo {
  border: 10px solid black;
  padding: 20px;
  background-color: lightblue;
  background-clip: padding-box;
}

En este ejemplo, el fondo azul claro se extiende solo hasta el borde del padding, sin cubrir el borde.
