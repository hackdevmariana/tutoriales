Propiedad display

La propiedad display en CSS es fundamental para controlar cómo se muestran los elementos en una página web.

Valores comunes de display

block: El elemento se muestra como un bloque, ocupando todo el ancho disponible y comenzando en una nueva línea.

div {
  display: block;
}

inline: El elemento se muestra en línea, ocupando solo el espacio necesario y sin comenzar en una nueva línea.

span {
  display: inline;
}

inline-block: Combina características de block e inline. El elemento se muestra en línea pero se comporta como un bloque, permitiendo definir ancho y alto.

img {
  display: inline-block;
}

none: El elemento no se muestra en la página. Es como si no existiera en el árbol del documento.

.oculto {
  display: none;
}

flex: El elemento se convierte en un contenedor flexible, permitiendo el uso de Flexbox para alinear y distribuir el contenido.

.contenedor {
  display: flex;
}

grid: El elemento se convierte en un contenedor de cuadrícula, permitiendo el uso de Grid Layout para organizar el contenido en filas y columnas.

.grid {
  display: grid;
}

Ejemplo de uso de display con flexbox

.contenedor {
  display: flex;
  justify-content: space-around;
}

.item {
  background-color: lightblue;
  padding: 10px;
  border: 1px solid blue;
}
