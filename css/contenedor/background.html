Propiedad background

La propiedad background de CSS es una propiedad abreviada que permite establecer varios aspectos del fondo de un elemento en una sola declaración.

Esta propiedad puede incluir:

  • background-color: El color de fondo.

  • background-image: Una o más imágenes de fondo.

  • background-position: La posición de las imágenes de fondo.

  • background-size: El tamaño de las imágenes de fondo.

  • background-repeat: Cómo se repiten las imágenes de fondo.

  • background-origin: El área de posicionamiento del fondo.

  • background-clip: El área de pintura del fondo.

  • background-attachment: Si el fondo es fijo o se desplaza con el contenido.

Ejemplo

body {
  background: lightblue url('img_tree.gif') no-repeat fixed center;
}

En este ejemplo:

  • El color de fondo es lightblue.

  • La imagen de fondo es img_tree.gif.

  • La imagen no se repite (no-repeat).

  • La imagen está fija (fixed).

  • La imagen está centrada (center).

Valores por defecto

Si no se especifica alguno de los valores, se utilizarán los valores por defecto de cada propiedad individual.
