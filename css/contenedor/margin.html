Propiedad margin

La propiedad margin en CSS se utiliza para crear espacio alrededor de los elementos, fuera de cualquier borde definido.

Propiedades de margin

margin-top: Establece el margen superior del elemento.

margin-right: Establece el margen derecho del elemento.

margin-bottom: Establece el margen inferior del elemento.

margin-left: Establece el margen izquierdo del elemento.

Sintaxis

Se pueden definir los márgenes de varias maneras:

Un solo valor: Aplica el mismo margen a todos los lados.

div {
  margin: 20px;
}

Dos valores: El primer valor es para los márgenes superior e inferior, y el segundo para los márgenes izquierdo y derecho.

div {
  margin: 20px 10px;
}

Tres valores: El primer valor es para el margen superior, el segundo para los márgenes izquierdo y derecho, y el tercero para el margen inferior.

div {
  margin: 20px 10px 5px;
}

Cuatro valores: Los valores se aplican en el orden: superior, derecho, inferior, izquierdo.

div {
  margin: 20px 10px 5px 15px;
}

Valores especiales

  • auto: El navegador calcula el margen automáticamente. Es útil para centrar elementos horizontalmente.
div {
  width: 50%;
  margin: 0 auto;
}
  • Valores negativos: Permiten reducir el espacio alrededor de un elemento.
div {
  margin: -10px;
}

Ejemplo práctico de cómo usar margin para centrar un elemento y añadir espacio alrededor de él

<!DOCTYPE html>
<html lang="es">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
  </head>
  <body>
    <div class="contenedor">
      Contenido centrado con márgenes.
    </div>
  </body>
</html>

.contenedor {
width: 300px;
margin: 50px auto;
padding: 20px;
border: 2px solid black;
background-color: lightblue;
}
