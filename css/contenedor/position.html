Propiedad position

La propiedad position en CSS es crucial para controlar cómo se posicionan los elementos en una página web.

Valores de position

static: Es el valor por defecto. Los elementos se posicionan según el flujo normal del documento. Las propiedades top, right, bottom y left no tienen efecto.

div {
  position: static;
}

relative: El elemento se posiciona relativo a su posición original en el flujo del documento. Las propiedades top, right, bottom y left desplazan el elemento desde su posición original.

div {
  position: relative;
  top: 10px;
  left: 20px;
}

absolute: El elemento se posiciona relativo a su contenedor más cercano que no tenga position: static. Si no hay tal contenedor, se posiciona relativo al <html>. Las propiedades top, right, bottom y left determinan su posición.

div {
  position: absolute;
  top: 50px;
  left: 100px;
}

fixed: El elemento se posiciona relativo a la ventana del navegador. Permanece en la misma posición incluso cuando se hace scroll.

div {
  position: fixed;
  top: 0;
  right: 0;
}

sticky: El elemento se comporta como relative hasta que se alcanza un umbral definido por top, right, bottom o left, momento en el cual se comporta como fixed.

div {
  position: sticky;
  top: 0;
}

Ejemplo de uso

<!DOCTYPE html>
<html lang="es">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
  </head>
  <body>
    <div class="static">Static</div>
    <div class="relative">Relative</div>
    <div class="absolute">Absolute</div>
    <div class="fixed">Fixed</div>
    <div class="sticky">Sticky</div>
  </body>
</html>

.static { position: static; background-color: lightgrey; }
.relative { position: relative; top: 10px; left: 20px; background-color: lightblue; }
.absolute { position: absolute; top: 50px; left: 100px; background-color: lightgreen; }
.fixed { position: fixed; top: 0; right: 0; background-color: lightcoral; }
.sticky { position: sticky; top: 0; background-color: lightgoldenrodyellow; }
