Propiedad padding

La propiedad padding en CSS es una propiedad que se utiliza para crear espacio alrededor del contenido de un elemento, dentro de sus bordes definidos. Este espacio adicional se conoce como "relleno" y se puede aplicar a los cuatro lados del elemento: superior, derecho, inferior e izquierdo.

Sintaxis

La propiedad padding se puede especificar utilizando uno, dos, tres o cuatro valores:

  • Un valor: Se aplica el mismo relleno a los cuatro lados.
.container{
  padding: 20px;
}
  • Dos valores: El primer valor se aplica a la parte superior e inferior, y el segundo a los lados derecho e izquierdo.
.container{
  padding: 10px 20px;
}
  • Tres valores: El primer valor se aplica a la parte superior, el segundo a los lados derecho e izquierdo, y el tercero a la parte inferior.
.container{
  padding: 10px 20px 30px;
}
  • Cuatro valores: Se aplican en el orden superior, derecho, inferior e izquierdo (en el sentido de las agujas del reloj).
.container{
  padding: 10px 20px 30px 40px;
}

Ejemplo

AplicaR 20px de relleno a todos los lados:

.caja {
  background-color: lightblue;
  padding: 20px;
}

Diferencia entre padding y margin

  • Padding: Crea espacio dentro de un elemento, entre su contenido y su borde.

  • Margin: Crea espacio alrededor de un elemento, fuera de sus bordes.

Propiedades relacionadas

  • padding-top: Establece el relleno en la parte superior.

  • padding-right: Establece el relleno en el lado derecho.

  • padding-bottom: Establece el relleno en la parte inferior.

  • padding-left: Establece el relleno en el lado izquierdo.
