Propiedad background-attachment

La propiedad background-attachment en CSS determina si la imagen de fondo de un elemento se desplaza con el contenido de la página o se mantiene fija.

Posibles valores

scroll (valor por defecto): La imagen de fondo se desplaza junto con el contenido de la página. Es decir, cuando el usuario hace scroll, la imagen de fondo se mueve.

.ejemplo {
  background-attachment: scroll;
}

fixed: La imagen de fondo se mantiene fija en la ventana del navegador y no se desplaza con el contenido de la página. Esto puede crear un efecto de paralaje (parallax).

.ejemplo {
  background-attachment: fixed;
}

local: La imagen de fondo se desplaza junto con el contenido del elemento al que está aplicada. Esto es útil cuando el elemento tiene un scroll interno.

.ejemplo {
  background-attachment: local;
}

Ejemplo práctico

.ejemplo {
  height: 200px;
  background-image: url('imagen.jpg');
  background-repeat: no-repeat;
  background-size: cover;
  background-attachment: fixed;
}

En este ejemplo, la imagen de fondo se mantendrá fija en la ventana del navegador mientras haces scroll.
