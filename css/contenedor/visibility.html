Propiedad visibility

La propiedad visibility en CSS se utiliza para controlar la visibilidad de un elemento en la página web. A diferencia de la propiedad display, que puede eliminar un elemento del flujo del documento, visibility oculta el elemento pero mantiene su espacio reservado en la página.

Valores de visibility

visible:

  • Valor por defecto. El elemento es visible.
.elemento {
  visibility: visible;
}

hidden:

  • El elemento está oculto, pero sigue ocupando espacio en el diseño de la página.
.elemento {
  visibility: hidden;
}

collapse:

  • Este valor se utiliza principalmente para filas y columnas de tablas. Oculta el elemento y colapsa el espacio que ocupa, similar a display: none para estos elementos específicos.
tr.colapsar {
  visibility: collapse;
}

inherit:

  • El elemento hereda el valor de visibility de su elemento padre.
.elemento {
  visibility: inherit;
}

Ejemplos de uso

Ocultar un elemento sin eliminar su espacio:

p.oculto {
  visibility: hidden;
}

Colapsar una fila de una tabla

tr.colapsar {
  visibility: collapse;
}

Diferencia entre visibility y display

  • visibility: hidden: Oculta el elemento pero mantiene su espacio reservado.

  • display: none: Oculta el elemento y elimina su espacio del flujo del documento.

Consideraciones

  • La propiedad visibility es útil cuando necesitas ocultar elementos temporalmente sin afectar el diseño de la página.

  • visibility: collapse puede no estar completamente soportado en todos los navegadores para elementos que no sean filas o columnas de tablas
