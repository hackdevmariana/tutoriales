Propiedad background-repeat

La propiedad background-repeat en CSS se utiliza para definir cómo se repite una imagen de fondo dentro de su contenedor. Aquí tienes una descripción detallada:

Sintaxis

div {
  background-repeat: repeat-style;
}

repeat-style: Puede ser uno de varios valores que determinan el comportamiento de repetición de la imagen de fondo.

Valores comunes

repeat: La imagen de fondo se repite tanto horizontal como verticalmente para cubrir todo el contenedor.

.example1 {
  background-image: url('image.jpg');
  background-repeat: repeat;
}

no-repeat: La imagen de fondo no se repite. Solo se muestra una vez.

.example2 {
  background-image: url('image.jpg');
  background-repeat: no-repeat;
}

repeat-x: La imagen de fondo se repite solo horizontalmente.

.example3 {
  background-image: url('image.jpg');
  background-repeat: repeat-x;
}

repeat-y: La imagen de fondo se repite solo verticalmente.

.example4 {
  background-image: url('image.jpg');
  background-repeat: repeat-y;
}

space: La imagen de fondo se repite tanto como sea posible sin recortar, y el espacio sobrante se distribuye alrededor de las imágenes.

.example5 {
  background-image: url('image.jpg');
  background-repeat: space;
}

round: La imagen de fondo se escala para que se repita un número entero de veces tanto horizontal como verticalmente, sin dejar espacio sobrante.

.example6 {
  background-image: url('image.jpg');
  background-repeat: round;
}

Ejemplo completo

.example7 {
  background-image: url('image.jpg');
  background-repeat: no-repeat;
  background-position: center;
  background-size: cover;
}

En este ejemplo, la imagen de fondo no se repite, se centra y se escala para cubrir todo el contenedor.
