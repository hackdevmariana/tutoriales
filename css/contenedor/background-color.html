Propiedad background-color

La propiedad background-color de CSS se utiliza para establecer el color de fondo de un elemento. Esta propiedad es muy útil para mejorar la apariencia visual de una página web y para resaltar elementos específicos.

Sintaxis

element {
  background-color: color;
}

Valores

  • color: Puede ser especificado de varias maneras:

  • Nombre de color: como red, blue, green, etc.

  • Valores HEX: como #ff0000, #00ff00, #0000ff, etc.

  • Valores RGB: como rgb(255, 0, 0), rgb(0, 255, 0), rgb(0, 0, 255), etc.

  • Valores RGBA: como rgba(255, 0, 0, 0.5) (el último valor es la opacidad).

  • Valores HSL: como hsl(0, 100%, 50%).

  • Valores HSLA: como hsla(0, 100%, 50%, 0.5).

Ejemplos

body {
  background-color: lightblue;
}

h1 {
  background-color: #ff6347;
}

p {
  background-color: rgb(255, 255, 0);
}

div {
  background-color: rgba(0, 0, 255, 0.3); 
}

Comportamiento

  • Valor por defecto: El valor por defecto de background-color es transparent, lo que significa que el fondo será transparente y mostrará el color del elemento subyacente.

  • Herencia: Esta propiedad no se hereda, lo que significa que cada elemento debe tener su propio valor de background-color si se desea un color de fondo específico
