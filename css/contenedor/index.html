Contenedores en CSS

Los contenedores en CSS son elementos fundamentales para estructurar y organizar el contenido de una página web.

Tipos de contenedores

Bloques (Block Elements): Estos elementos ocupan todo el ancho disponible y comienzan en una nueva línea. Ejemplos comunes son <div>, <p>, <h1>, etc.

En línea (Inline Elements): Estos elementos solo ocupan el espacio necesario para su contenido y no comienzan en una nueva línea. Ejemplos incluyen <span>, <a>, <strong>, etc.

En línea-bloque (Inline-Block Elements): Combinan características de los elementos en línea y de bloque. Ocupan solo el espacio necesario, pero permiten definir propiedades de ancho y alto. Un ejemplo es <img>.

Propiedades principales

Display: Controla cómo se muestra un contenedor.

  • block: El elemento se muestra como un bloque.

  • inline: El elemento se muestra en línea.

  • inline-block: El elemento se muestra en línea pero se comporta como un bloque.

  • none: El elemento no se muestra.

Position: Define cómo se posiciona un contenedor en la página.

  • static: Posición por defecto, sigue el flujo normal del documento.

  • relative: Posicionado relativo a su posición original.

  • absolute: Posicionado relativo a su contenedor más cercano con posición relativa, absoluta o fija.

  • fixed: Posicionado relativo a la ventana del navegador.

  • sticky: Se comporta como relative hasta que se alcanza un umbral, luego se comporta como fixed.

Box Model: Describe el diseño y el espacio que ocupa un contenedor.

  • Margin: Espacio exterior alrededor del contenedor.

  • Border: Borde alrededor del contenedor.

  • Padding: Espacio interior entre el contenido y el borde del contenedor.

  • Content: El contenido real del contenedor.

Ejemplo de uso

Un ejemplo básico de un contenedor <div> con algunas propiedades CSS aplicadas:

div.contenedor {
  width: 300px;
  height: 200px;
  margin: 20px auto;
  padding: 10px;
  border: 2px solid black;
  background-color: lightblue;
  position: relative;
}

Este código crea un contenedor de 300px de ancho y 200px de alto, centrado horizontalmente con márgenes automáticos, un relleno de 10px, un borde negro de 2px y un fondo azul claro.

Ventajas de usar contenedores

  • Organización: Facilitan la organización y el diseño del contenido.

  • Flexibilidad: Permiten crear diseños responsivos y adaptativos.

  • Control: Ofrecen un control preciso sobre el espaciado, alineación y tamaño de los elementos.
