Propiedad background-size

La propiedad background-size en CSS se utiliza para especificar el tamaño de la imagen de fondo.

Sintaxis

div
{
  background-size: width height;
}

  • width: El ancho de la imagen de fondo (puede ser un valor en píxeles, porcentaje, o palabras clave como auto, cover, contain).

  • height: La altura de la imagen de fondo (puede ser un valor en píxeles, porcentaje, o palabras clave como auto).

Valores comunes

auto: Mantiene el tamaño original de la imagen.

.example1 {
  background-image: url('image.jpg');
  background-size: auto;
}

cover: Escala la imagen para cubrir todo el contenedor, manteniendo la proporción de aspecto. Puede recortar partes de la imagen si es necesario.

.example2 {
  background-image: url('image.jpg');
  background-size: cover;
}

contain: Escala la imagen para que quepa completamente dentro del contenedor, manteniendo la proporción de aspecto. Puede dejar espacio vacío si las proporciones no coinciden.

.example3 {
  background-image: url('image.jpg');
  background-size: contain;
}

Valores específicos: Puedes definir tamaños específicos en píxeles o porcentajes.

Ancho de 100px y alto de 200px:

.example4 {
  background-image: url('image.jpg');
  background-size: 100px 200px;
}

Ancho y alto al 50% del contenedor:

.example5 {
  background-image: url('image.jpg');
  background-size: 50% 50%;
}

Ejemplo Completo

.example6 {
  background-image: url('image.jpg');
  background-size: cover;
  background-position: center;
  background-repeat: no-repeat;
}

En este ejemplo, la imagen de fondo se escala para cubrir todo el contenedor, se centra y no se repite.
