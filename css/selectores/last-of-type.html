Pseudoclase last-of-type

La pseudo-clase :last-of-type en CSS se utiliza para seleccionar el último elemento de su tipo entre un grupo de elementos hermanos. Esto es útil cuando quieres aplicar estilos específicos al último elemento de un tipo particular dentro de un contenedor.

Sintaxis

selector:last-of-type {
  /* Declaraciones CSS */
}

Ejemplo básico

Supongamos que tenemos varios párrafos dentro de un contenedor y queremos aplicar un estilo especial solo al último párrafo:

<div>
  <p>Primer párrafo</p>
  <p>Segundo párrafo</p>
  <p>Último párrafo</p>
</div>

Para cambiar el color de texto del último <p>, usaríamos:

p:last-of-type {
  color: blue;
}
