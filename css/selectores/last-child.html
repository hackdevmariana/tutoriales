Pseudoclase last-child

La pseudo-clase :last-child en CSS se utiliza para seleccionar el último elemento entre un grupo de elementos hermanos. Esto es útil cuando quieres aplicar estilos específicos al último elemento de una lista, un contenedor, o cualquier otro grupo de elementos.

Sintaxis

selector:last-child {
  /* Declaraciones CSS */
}

Ejemplo básico

Supongamos que tenemos una lista de elementos <li> y queremos aplicar un estilo especial solo al último elemento:

<ul>
  <li>Elemento 1</li>
  <li>Elemento 2</li>
  <li>Elemento 3</li>
</ul>

Para cambiar el color de texto del último <li>, usaríamos:

li:last-child {
  color: red;
}

Hay que considerar que :last-child selecciona el último hijo de su padre, sin importar el tipo de elemento. Si necesitamos seleccionar el último hijo de un tipo específico, podemos usar :last-of-type.
