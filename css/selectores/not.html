Pseudoclase not

La pseudo-clase :not() en CSS se utiliza para seleccionar elementos que no coinciden con un selector específico. Es conocida como la pseudo-clase de negación y es muy útil para aplicar estilos a todos los elementos excepto a aquellos que coinciden con un selector dado.

Sintaxis

selector:not(selector) {
  /* Declaraciones CSS */
}

Ejemplo básico

Supongamos que tenemos una lista de elementos <li> y queremos aplicar un estilo a todos los elementos excepto al que tiene la clase .excluir:

<ul>
  <li>Elemento 1</li>
  <li class="excluir">Elemento 2</li>
  <li>Elemento 3</li>
</ul>

Para aplicar un estilo a todos los <li> excepto al que tiene la clase .excluir, usarías:

li:not(.excluir) {
  color: blue;
}
