Pseudoclase first-child

La pseudo-clase :first-child en CSS se utiliza para seleccionar el primer elemento hijo de su padre entre un grupo de elementos hermanos. Esto es útil cuando quieres aplicar estilos específicos al primer elemento de una lista, un contenedor, o cualquier otro elemento HTML.

Sintaxis

selector:first-child {
  /* Declaraciones CSS */
}

Ejemplos de uso

Seleccionar el primer párrafo dentro de un contenedor:

p:first-child {
  color: blue;
}

<div>
  <p>Este párrafo será azul.</p>
  <p>Este párrafo no será azul.</p>
</div>

Aplicar estilos al primer elemento de una lista:

li:first-child {
  font-weight: bold;
}

<ul>
  <li>Este ítem será negrita.</li>
  <li>Este ítem no será negrita.</li>
</ul>

Consideraciones

  • Elementos hermanos: :first-child selecciona el primer elemento hijo de su padre, por lo que si el primer hijo no es del tipo de elemento que estás seleccionando, no se aplicará el estilo.

  • Uso combinado: podemos combinar :first-child con otros selectores para mayor especificidad, como ul > li:first-child para seleccionar el primer li dentro de un ul.
