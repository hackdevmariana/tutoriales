Selector de tipo

El selector de tipo en CSS se utiliza para seleccionar todos los elementos de un tipo específico dentro de un documento HTML. Este selector se basa en el nombre del elemento o nodo. Por ejemplo, si queremos aplicar estilos a todos los párrafos (<p>) en una página, usaríamos el selector de tipo p.

Ejemplo básico

p {
  color: blue;
  font-size: 16px;
}

En este caso, todos los elementos <p> en el documento tendrán el texto de color azul y un tamaño de fuente de 16 píxeles.

Características del selector de tipo

  • Sintaxis: La sintaxis es simplemente el nombre del elemento seguido de las reglas de estilo entre llaves.

  • Aplicación: Se aplica a todos los elementos del tipo especificado en el documento.

  • Especificidad: Tiene una especificidad baja, lo que significa que puede ser fácilmente sobrescrito por selectores más específicos como clases o identificadores.

Ejemplo práctico

Dado el siguiente HTML y CSS:

<!DOCTYPE html>
<html lang="es">
  <head>
    <meta charset="UTF-8">
    <title>Ejemplo de Selector de Tipo</title>
  </head>
  <body>
    <h1>Este es un encabezado</h1>
    <p>Este es un párrafo.</p>
    <p>Este es otro párrafo.</p>
  </body>
</html>

h1 {
  color: green;
}
p {
  color: blue;
}

El CSS aplicará el color verde al texto del <h1> y el color azul a todos los <p>.
