Pseudoclase focus

La pseudoclase :focus en CSS se utiliza para aplicar estilos a un elemento que ha recibido el foco. Un elemento recibe el foco cuando el usuario hace clic en él, lo toca en una pantalla táctil, o lo selecciona mediante la tecla "Tab" del teclado. Esta pseudoclase es especialmente útil para mejorar la accesibilidad y la experiencia del usuario, ya que permite resaltar visualmente el elemento con el que el usuario está interactuando.

Ejemplo básico de uso

input:focus {
  background-color: yellow;
  border: 2px solid blue;
}

En este ejemplo, cualquier elemento <input> cambiará su color de fondo a amarillo y su borde a azul cuando reciba el foco.

Importancia de la pseudoclase :focus

  • Accesibilidad: Ayuda a los usuarios que navegan con el teclado a identificar fácilmente el elemento activo.

  • Experiencia de Usuario: Proporciona retroalimentación visual inmediata, mejorando la interacción con la página.

Buenas prácticas

  • No eliminar el outline sin reemplazo: El outline predeterminado es crucial para la accesibilidad. Si decidimos eliminarlo, deberíamos asegurarnos de proporcionar otro indicador visual claro.
input:focus {
  outline: none;
  box-shadow: 0 0 5px rgba(81, 203, 238, 1);
}

En este ejemplo, se reemplaza el outline con una sombra azul.

Relación con otras pseudoclases

  • :focus-within: Selecciona un elemento si él o cualquiera de sus descendientes tiene el foco.
form:focus-within {
  border: 2px solid green;
}

En este ejemplo, el borde del formulario se vuelve verde si cualquier elemento dentro del formulario tiene el foco.

input:focus {
  background-color: yellow;
  border: 2px solid blue;
}
form:focus-within {
  border: 2px solid green;
}

En este ejemplo, los campos de entrada cambiarán de estilo cuando reciban el foco, y el formulario cambiará su borde si cualquiera de sus elementos tiene el foco.
