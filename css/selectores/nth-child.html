Pseudoclase nth-child

La pseudo-clase :nth-child() en CSS se utiliza para seleccionar uno o más elementos en función de su posición entre un grupo de hermanos. Es muy versátil y permite aplicar estilos a elementos específicos basados en su orden dentro de su contenedor padre.

Sintaxis

selector:nth-child(an+b) {
  /* Declaraciones CSS */
}

Valores comunes

  • Número: Selecciona el enésimo hijo. Por ejemplo, :nth-child(3) selecciona el tercer hijo.

  • odd: Selecciona todos los hijos en posiciones impares (1, 3, 5, ...).

  • even: Selecciona todos los hijos en posiciones pares (2, 4, 6, ...).

  • an+b: Selecciona elementos basados en una fórmula. Por ejemplo, 2n+1 selecciona todos los elementos en posiciones impares.

Ejemplos

Seleccionar elementos impares y pares

li:nth-child(odd) {
  background-color: lightgray;
}

li:nth-child(even) {
  background-color: white;
}

Usar una fórmula

li:nth-child(3n+1) {
  color: blue;
}

En este ejemplo, se seleccionan los elementos en las posiciones 1, 4, 7, etc.

Ejemplo en HTML y CSS

<!DOCTYPE html>
<html lang="es">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Ejemplo de :nth-child()</title>
  </head>
  <body>
    <ul>
      <li>Elemento 1</li>
      <li>Elemento 2</li>
      <li>Elemento 3</li>
      <li>Elemento 4</li>
      <li>Elemento 5</li>
      <li>Elemento 6</li>
    </ul>
  </body>
</html>

li:nth-child(odd) {
  background-color: lightgray;
}
li:nth-child(even) {
  background-color: white;
}
li:nth-child(3n+1) {
  color: blue;
}

En este ejemplo, los elementos impares tienen un fondo gris claro, los pares tienen un fondo blanco, y cada tercer elemento empezando desde el primero tiene el texto en azul.

Hay que considerar que :nth-child() selecciona elementos basados en su posición entre todos los hijos, no solo los de un tipo específico. Para seleccionar elementos de un tipo específico, podemos usar :nth-of-type().
