Pseudoclase active

La pseudoclase :active en CSS se utiliza para aplicar estilos a un elemento mientras está siendo activado por el usuario. Esto generalmente ocurre cuando el usuario hace clic en el elemento y mantiene presionado el botón del mouse. La pseudoclase :active es comúnmente utilizada en elementos interactivos como enlaces (<a>) y botones (<button>).

Ejemplo de uso

a:active {
  color: red;
}

En este ejemplo, cualquier enlace (<a>) cambiará su color a rojo mientras está siendo activado (es decir, mientras se mantiene presionado el botón del mouse sobre el enlace).

Orden de las pseudoclases

Es importante tener en cuenta el orden de las pseudoclases cuando se aplican estilos a enlaces.

El orden recomendado es LVHA:

  1. :link - Enlaces no visitados.

  2. :visited - Enlaces visitados.

  3. :hover - Enlaces cuando el usuario pasa el mouse sobre ellos.

  4. :active - Enlaces cuando están siendo activados.

Ejemplo completo

a:link {
  color: blue;
}
a:visited {
  color: purple;
}
a:hover {
  background: yellow;
}
a:active {
  color: lime;
}

En este ejemplo, el enlace cambiará de color a lima mientras está siendo activado.
