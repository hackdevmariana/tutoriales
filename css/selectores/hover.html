Pseudoclase hover

La pseudoclase :hover en CSS se utiliza para aplicar estilos a un elemento cuando el usuario pasa el cursor sobre él. Es una de las pseudoclases más comunes y se usa frecuentemente para mejorar la interactividad y la experiencia del usuario en una página web.

Ejemplo de uso

Estilo base para los enlaces:

a {
  color: blue;
  text-decoration: none;
}

Cambia el color del enlace cuando el usuario pasa el cursor sobre él:

a:hover {
  color: red;
}

En este ejemplo, los enlaces (<a>) tendrán un color azul por defecto, pero cambiarán a rojo cuando el usuario pase el cursor sobre ellos.

Aplicaciones comunes

  • Enlaces: Cambiar el color, subrayado o fondo de los enlaces para indicar que son interactivos.

  • Botones: Cambiar el color de fondo, el borde o el texto de los botones para proporcionar retroalimentación visual.

  • Imágenes: Aplicar efectos como aumentar el tamaño o cambiar la opacidad de las imágenes al pasar el cursor sobre ellas.

Ejemplo avanzado

Aquí tenemos un ejemplo más avanzado que muestra cómo :hover puede ser utilizado en diferentes elementos:

Estilo base para los botones:

button {
  background-color: lightblue;
  border: none;
  padding: 10px 20px;
  cursor: pointer;
}

Cambiar el fondo y el color del texto del botón al pasar el cursor:

button:hover {
  background-color: darkblue;
  color: white;
}

Estilo base para las imágenes:

img {
  width: 100px;
  transition: transform 0.3s ease;
}

Aumentar el tamaño de la imagen al pasar el cursor:

img:hover {
  transform: scale(1.2);
}

En este ejemplo:

  • Los botones cambian su color de fondo a azul oscuro y el color del texto a blanco cuando el usuario pasa el cursor sobre ellos.

  • Las imágenes aumentan de tamaño suavemente al pasar el cursor sobre ellas, gracias a la propiedad transform y la transición.
