Selectores en CSS

Los selectores en CSS son fundamentales para aplicar estilos a elementos específicos en una página web.

Tipos más comunes

Selector de tipo: Selecciona todos los elementos que coinciden con el nombre del elemento especificado.

  • Sintaxis: elemento

  • Ejemplo: p selecciona todos los párrafos <p>.

Selector de clase: Selecciona todos los elementos que tienen una clase específica.

  • Sintaxis: .nombreDeClase

  • Ejemplo: .boton selecciona todos los elementos con la clase boton.

Selector de ID: Selecciona un elemento basado en su ID único.

  • Sintaxis: #nombreDeID

  • Ejemplo: #cabecera selecciona el elemento con el ID cabecera.

Selector universal: Selecciona todos los elementos.

  • Sintaxis: *

  • Ejemplo: * aplica a todos los elementos del documento.

Selector de atributo: Selecciona elementos basándose en el valor de un atributo específico.

  • Sintaxis: [atributo], [atributo=valor]

  • Ejemplo: [type="text"] selecciona todos los elementos <input> con type="text".

Combinadores: Permiten seleccionar elementos basados en su relación con otros elementos.

  • Combinador de descendientes: A B selecciona todos los elementos B que son descendientes de A.

  • Combinador de hijo: A > B selecciona todos los elementos B que son hijos directos de A.

  • Combinador de hermanos adyacentes: A + B selecciona el elemento B que sigue inmediatamente a A.

  • Combinador de hermanos generales: A ~ B selecciona todos los elementos B que son hermanos de A.

Pseudoclases: Seleccionan elementos basados en su estado.

  • Ejemplo: a:hover selecciona los enlaces cuando el usuario pasa el cursor sobre ellos.

Pseudoelementos: Permiten seleccionar partes de un elemento.

  • Ejemplo: p::first-line selecciona la primera línea de todos los párrafos.
