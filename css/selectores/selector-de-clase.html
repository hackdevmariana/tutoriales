Selector de clase

El selector de clase en CSS se utiliza para seleccionar elementos que tienen un atributo class específico. Este selector se define utilizando un punto (.) seguido del nombre de la clase. Es muy útil para aplicar estilos a múltiples elementos sin tener que repetir las reglas de estilo.

Ejemplo básico

Si tenemos el siguiente HTML y CSS:

<!DOCTYPE html>
<html lang="es">
<head>
  <meta charset="UTF-8">
  <title>Ejemplo de selector de clase</title>
</head>
<body>
  <p class="mi-clase">Este es un párrafo con la clase "mi-clase".</p>
  <div class="mi-clase">Este es un div con la clase "mi-clase".</div>
</body>
</html>

.mi-clase {
  color: red;
  font-size: 20px;
}

En este ejemplo, tanto el párrafo (<p>) como el div (<div>) tendrán el texto de color rojo y un tamaño de fuente de 20 píxeles.

Características del selector de clase

  • Sintaxis: .nombre-de-clase { reglas de estilo }

  • Aplicación: Se aplica a todos los elementos que tienen el atributo class con el nombre especificado.

  • Especificidad: Tiene una especificidad mayor que el selector de tipo, pero menor que el selector de ID.

Ejemplos prácticos

Seleccionar todos los elementos con la clase "resaltado":

.resaltado {
  background-color: yellow;
}

Seleccionar sólo los párrafos con la clase "importante":

p.importante {
  font-weight: bold;
}

En este caso, todos los elementos con la clase resaltado tendrán un fondo amarillo, y solo los párrafos (<p>) con la clase importante tendrán el texto en negrita.
