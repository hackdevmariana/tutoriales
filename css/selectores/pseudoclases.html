Pseudoclases

Las pseudoclases en CSS son palabras clave que se añaden a los selectores para especificar un estado especial del elemento seleccionado. Permiten aplicar estilos a elementos en función de su estado o posición en el documento, sin necesidad de agregar clases adicionales en el HTML.

Algunas de las pseudoclases más comunes

  • :hover: Se aplica cuando el usuario pasa el cursor sobre un elemento.

  • :active: Se aplica cuando un elemento está siendo activado, como durante el clic.

  • :focus: Se aplica cuando un elemento ha recibido el foco, por ejemplo, al ser seleccionado mediante el teclado.

  • :visited: Se aplica a los enlaces que el usuario ya ha visitado.

  • :first-child: Se aplica al primer hijo de un elemento padre.

  • :last-child: Se aplica al último hijo de un elemento padre.

  • :nth-child(n): Se aplica al enésimo hijo de un elemento padre, donde n puede ser un número, una palabra clave o una fórmula.

  • :not(selector): Se aplica a todos los elementos que no coinciden con el selector especificado.

Ejemplos

Estilo base para los enlaces:

a {
  color: blue;
  text-decoration: none;
}

Cambiar el color del enlace cuando el usuario pasa el cursor sobre él:

a:hover {
  color: red;
}

Cambiar el color del enlace cuando está siendo activado (clic):

a:active {
  color: green;
}

Cambiar el color del enlace cuando tiene el foco:

a:focus {
  outline: 2px solid orange;
}

Estilo para el primer hijo de un elemento:

p:first-child {
  font-weight: bold;
}

Estilo para el último hijo de un elemento:

p:last-child {
  font-style: italic;
}

Estilo para el tercer hijo de un elemento:

p:nth-child(3) {
  color: purple;
}

Estilo para los elementos que no son de tipo párrafo:

:not(p) {
  background-color: lightgray;
}

En estos ejemplo:

  • Los enlaces (<a>) cambian de color según su estado: rojo al pasar el cursor, verde al hacer clic y tienen un borde naranja cuando reciben el foco.

  • El primer párrafo dentro de un contenedor se muestra en negrita.

  • El último párrafo se muestra en cursiva.

  • El tercer hijo de un contenedor se muestra en color púrpura.

  • Los elementos que no son párrafos tienen un fondo gris claro.
