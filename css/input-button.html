Cambiar el estilo de un input button con CSS

Los radio buttons en CSS pueden ser estilizados de varias maneras para mejorar su apariencia y funcionalidad.

Veamos algunas propiedades y técnicas comunes para personalizarlos:

width y height: Ajusta el tamaño del radio button.

input[type="radio"] {
  width: 20px;
  height: 20px;
}

background-color: Cambia el color de fondo del radio button.

input[type="radio"] {
  background-color: #f0f0f0;
}

border: Controla el estilo, el grosor y el color del borde.

input[type="radio"] {
  border: 2px solid #000;
}

box-shadow: Añade sombras para darle un efecto de profundidad.

input[type="radio"] {
  box-shadow: 2px 2px 5px rgba(0, 0, 0, 0.3);
}

border-radius: Redondea las esquinas del radio button.

input[type="radio"] {
  border-radius: 50%;
}

Pseudo-clase :checked: Aplica estilos cuando el radio button está seleccionado.

input[type="radio"]:checked {
  background-color: #007bff;
  border-color: #007bff;
}

Estilizar con label: Podemos usar etiquetas label para personalizar los radio buttons de manera más avanzada.

input[type="radio"] {
  display: none;
}

input[type="radio"] + label {
  display: inline-block;
  width: 20px;
  height: 20px;
  background-color: #f0f0f0;
  border-radius: 50%;
  border: 2px solid #000;
  cursor: pointer;
}

input[type="radio"]:checked + label {
  background-color: #007bff;
  border-color: #007bff;
}
