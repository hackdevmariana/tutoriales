Pseudo-elemento ::before

El pseudo-elemento ::before en CSS se utiliza para insertar contenido antes del contenido de un elemento seleccionado.

Sintaxis básica

selector::before {
  content: "texto o contenido";
}

Ejemplo simple

p::before {
  content: "Nota: ";
}

En este ejemplo, se añade el texto "Nota: " antes del contenido de cada elemento <p>.

Usos comunes

  • Añadir iconos o símbolos: podemos usar ::before para añadir iconos, flechas, o cualquier otro contenido decorativo.
a::before {
  content: "";
}
  • Citas: también podemos añadir comillas antes y después de citas.
q::before {
  content: "«";
}
q::after {
  content: "»";
}
