Propiedad hyphens

La propiedad hyphens de CSS se utiliza para controlar cómo se dividen las palabras cuando el texto se ajusta a través de múltiples líneas. Esta propiedad puede mejorar la legibilidad del texto en elementos de bloque.

Valores y usos

  • none: Las palabras no se dividen en los saltos de línea, incluso si los caracteres dentro de las palabras sugieren puntos de ruptura.

  • manual: Las palabras se dividen en los saltos de línea solo donde los caracteres dentro de la palabra sugieren oportunidades de ruptura, como los guiones suaves ().

  • auto: El navegador puede dividir automáticamente las palabras en puntos de guionización apropiados según las reglas del idioma especificado.

Para que la guionización automática funcione correctamente, es importante especificar el idioma del contenido usando el atributo lang en HTML

Ejemplos

Sin guionización:

p {
  hyphens: none;
}

En este caso, las palabras no se dividirán en los saltos de línea, incluso si hay caracteres que sugieren puntos de ruptura.

Guionización manual

p {
  hyphens: manual;
}

Con este valor, las palabras se dividirán solo en los puntos de ruptura manuales, como los guiones suaves ().

Guionización automática

p {
  hyphens: auto;
}

Aquí, el navegador dividirá automáticamente las palabras en los puntos de guionización apropiados según las reglas del idioma especificado.
