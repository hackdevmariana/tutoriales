Propiedad text-indent

La propiedad text-indent en CSS se utiliza para especificar la cantidad de espacio horizontal que se debe aplicar antes del comienzo de la primera línea de texto en un elemento de bloque.

Principales características

  • Valores: Puede aceptar valores en unidades de longitud (px, em, rem, etc.) o porcentajes. Los valores negativos también son permitidos, lo que hace que la primera línea se indente hacia la izquierda.

  • Valor inicial: El valor por defecto es 0.

  • Herencia: Esta propiedad es heredada, lo que significa que los elementos hijos pueden heredar el valor de su elemento padre.

  • Aplicación: Se aplica a elementos de bloque y celdas de tabla.

Ejemplos de Uso

Indentación positiva:

p {
  text-indent: 50px;
}

Este código aplicará una sangría de 50 píxeles a la primera línea de cada párrafo.

Indentación negativa:

p {
text-indent: -2em;
}

Este código moverá la primera línea de cada párrafo 2em hacia la izquierda.

Indentación en porcentaje:

p {
  text-indent: 10%;
}

Este código aplicará una sangría del 10% del ancho del elemento contenedor a la primera línea de cada párrafo.
