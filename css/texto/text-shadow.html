Propiedad text-shadow

La propiedad text-shadow de CSS se utiliza para añadir sombras al texto, lo que puede mejorar su apariencia y legibilidad.

Sintaxis

  • text-shadow: offset-x offset-y blur-radius color;

Valores

  • offset-x: La distancia horizontal de la sombra. Un valor positivo desplaza la sombra a la derecha, mientras que un valor negativo la desplaza a la izquierda.

  • offset-y: La distancia vertical de la sombra. Un valor positivo desplaza la sombra hacia abajo, mientras que un valor negativo la desplaza hacia arriba.

  • blur-radius (opcional): El radio de difuminado de la sombra. Un valor mayor hace que la sombra sea más difusa.

  • color (opcional): El color de la sombra. Si no se especifica, se usa el color predeterminado del navegador.

Ejemplos

Sombra simple:

h1 {
  text-shadow: 2px 2px;
}

Este ejemplo añade una sombra de 2 píxeles a la derecha y 2 píxeles hacia abajo del texto.

Sombra con color:

h1 {
  text-shadow: 2px 2px red;
}

Aquí, la sombra es de color rojo.

Sombra con difuminado:

h1 {
  text-shadow: 2px 2px 5px red;
}

Este ejemplo añade una sombra roja con un difuminado de 5 píxeles.

Múltiples sombras:

h1 {
  text-shadow: 1px 1px 2px black, 0 0 5px blue, 0 0 10px darkblue;
}
