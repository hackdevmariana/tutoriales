Propiedad overflow-wrap

La propiedad overflow-wrap en CSS se utiliza para controlar cómo se manejan las palabras largas que podrían desbordar el contenedor de un elemento. Esta propiedad permite que el navegador inserte saltos de línea dentro de una cadena de texto que de otro modo sería ininterrumpida, evitando así problemas de diseño debido al desbordamiento.

Valores

  • normal: Las líneas solo pueden romperse en puntos de quiebre normales de palabras (como un espacio entre dos palabras). Este es el valor por defecto.

  • break-word: Las palabras largas se romperán si desbordan el contenedor. Este valor es similar a anywhere, pero las oportunidades de ajuste suave introducidas por el quiebre de palabras no se consideran al calcular los tamaños intrínsecos de contenido mínimo.

  • anywhere: Para evitar el desbordamiento, una cadena de caracteres que de otro modo sería ininterrumpida (como una palabra larga o una URL) puede romperse en cualquier punto si no hay puntos de quiebre aceptables en la línea. No se inserta un carácter de guion en el punto de quiebre.

Ejemplo de uso

.long-text {
  overflow-wrap: break-word;
}
