Propiedad word-spacing

La propiedad word-spacing en CSS se utiliza para controlar el espacio entre las palabras en un texto.

Valores

  • normal: Usa el espacio estándar entre palabras (valor por defecto).

  • length: Define un espacio adicional entre palabras, que puede ser positivo o negativo (por ejemplo, 10px, 1em, -0.5em).

  • initial: Establece la propiedad a su valor inicial.

  • inherit: Hereda el valor de su elemento padre.

Ejemplos de uso

p {
  word-spacing: 10px;
}

En este ejemplo, el espacio entre las palabras en los elementos <p> será de 10 píxeles adicionales.

Con animación:

<p class="animated-text">Este es un ejemplo de animación con word-spacing en CSS.</p>


.animated-text {
  font-size: 20px;
  animation: wordSpacingAnimation 3s infinite alternate;
}

@keyframes wordSpacingAnimation {
  0% {
    word-spacing: 0px;
  }
  100% {
    word-spacing: 20px;
  }
}

Explicación:

La clase .animated-text aplica una animación llamada wordSpacingAnimation que dura 3 segundos y se repite infinitamente, alternando entre los estados inicial y final.

La regla @keyframes define la animación, comenzando con un word-spacing de 0px y aumentando gradualmente hasta 20px.
