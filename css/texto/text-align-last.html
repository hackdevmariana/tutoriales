Propiedad text-align-last

La propiedad text-align-last de CSS se utiliza para especificar cómo se alinea la última línea de un bloque de texto. Esto es particularmente útil cuando se desea controlar la alineación de la última línea de un párrafo o de un elemento de bloque que contiene texto justificado.

Valores

  • auto: Este es el valor por defecto. La última línea se alinea de acuerdo con el valor de text-align.

  • left: La última línea se alinea a la izquierda.

  • right: La última línea se alinea a la derecha.

  • center: La última línea se centra.

  • justify: La última línea se justifica como el resto de las líneas.

  • start: La última línea se alinea al inicio del contenedor (izquierda si la dirección del texto es de izquierda a derecha, y derecha si es de derecha a izquierda).

  • end: La última línea se alinea al final del contenedor (derecha si la dirección del texto es de izquierda a derecha, y izquierda si es de derecha a izquierda).

Ejemplo

div {
  text-align: justify;
  text-align-last: right;
}

En este ejemplo, el texto dentro del div se justifica, pero la última línea se alinea a la derecha.

Casos de uso

  • Diseños justificados: Mejora la apariencia de bloques de texto justificados al controlar la alineación de la última línea.

  • Textos multilingües: Facilita la presentación de textos en diferentes idiomas y direcciones de escritura.

  • Control de diseño: Permite un mayor control sobre la presentación del texto en un sitio web, especialmente en diseños complejos.
