Propiedad color

La propiedad color en CSS se utiliza para definir el color del texto en un elemento HTML

Ejemplo básico:

selector {
  color: valor;
}

La propiedad color acepta lo siguientes valores:

  • Nombres de colores: red, blue, green, etc.

  • Colores hexadecimales: #RRGGBB o #RRGGBBAA (con transparencia).

  • Valores RGB/RGBA: rgb(255, 0, 0) o rgba(255, 0, 0, 0.5) (con transparencia).

  • Valores HSL/HSLA: hsl(120, 100%, 50%) o hsla(120, 100%, 50%, 0.5) (con transparencia).

Ejemplos

Rojo en formato hexadecimal:

p {
  color: #FF0000;
}

Verde en formato RGB:

h1 {
  color: rgb(0, 128, 0);
}

Azul en formato HSL:

span {
  color: hsl(240, 100%, 50%);
}

Uso de currentcolor

El valor currentcolor se puede usar para aplicar el color actual del texto a otras propiedades, como border-color o background-color.

Borde azul:

div {
  color: blue;
  border: 1px solid currentcolor;
}
