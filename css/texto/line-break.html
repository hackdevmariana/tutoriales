Propiedad line-break

La propiedad line-break de CSS se utiliza para controlar cómo se manejan los saltos de línea en un bloque de texto. Esta propiedad es especialmente útil para textos en idiomas que no utilizan espacios para separar palabras, como el chino, japonés o tailandés, y para asegurar una correcta visualización en diferentes dispositivos y tamaños de pantalla.

Valores

  • auto: Este es el valor por defecto. El navegador decide automáticamente dónde realizar los saltos de línea.

  • loose: Permite saltos de línea más flexibles, incluso en lugares donde normalmente no se permitirían según las reglas del idioma.

  • normal: Realiza los saltos de línea de acuerdo con las reglas estándar del idioma.

  • strict: Realiza los saltos de línea solo en puntos permitidos según las reglas más estrictas del idioma.

  • anywhere: Permite saltos de línea en cualquier lugar, incluso dentro de palabras largas.

Ejemplo

p {
  line-break: strict;
}

En este ejemplo, los saltos de línea en los párrafos se realizarán solo en puntos permitidos según las reglas estrictas del idioma.
