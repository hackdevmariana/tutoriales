Propiedad direction

La propiedad direction de CSS se utiliza para establecer la dirección del flujo de contenido dentro de un elemento de nivel de bloque. Esta propiedad es especialmente útil para idiomas que se escriben de derecha a izquierda, como el árabe o el hebreo, para asegurar una correcta representación del texto.

Valores

  • ltr: El contenido, texto y otros elementos fluyen de izquierda a derecha. Este es el valor predeterminado.

  • rtl: El contenido, texto y otros elementos fluyen de derecha a izquierda.

Ejemplo

div {
  direction: rtl;
}

En este ejemplo, el texto dentro del div se mostrará de derecha a izquierda.
