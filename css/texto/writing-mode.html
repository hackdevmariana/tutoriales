Propiedad writing-mode

La propiedad writing-mode de CSS se utiliza para definir si las líneas de texto se disponen horizontal o verticalmente y la dirección en la que avanzan los bloques de texto. Esta propiedad es especialmente útil para manejar textos en idiomas que se escriben verticalmente, como el chino, japonés o coreano, así como para crear diseños más creativos y flexibles.

Valores

  • horizontal-tb: Este es el valor por defecto. El contenido fluye horizontalmente de izquierda a derecha y verticalmente de arriba hacia abajo.

  • vertical-rl: El contenido fluye verticalmente de arriba hacia abajo y horizontalmente de derecha a izquierda. El siguiente renglón vertical se posiciona a la izquierda del renglón anterior.

  • vertical-lr: El contenido fluye verticalmente de arriba hacia abajo y horizontalmente de izquierda a derecha. El siguiente renglón vertical se posiciona a la derecha del renglón anterior.

  • sideways-rl: El contenido fluye verticalmente de arriba hacia abajo, pero los glifos se colocan de lado hacia la derecha.

  • sideways-lr: El contenido fluye verticalmente de arriba hacia abajo, pero los glifos se colocan de lado hacia la izquierda.

Ejemplo

p.horizontal {
  writing-mode: horizontal-tb;
}

p.vertical {
  writing-mode: vertical-rl;
}

En este ejemplo, el párrafo con la clase horizontal tendrá el texto dispuesto horizontalmente, mientras que el párrafo con la clase vertical tendrá el texto dispuesto verticalmente de arriba hacia abajo y de derecha a izquierda.
