Propiedad

La propiedad line-height en CSS se utiliza para establecer la altura de cada línea de texto dentro de un elemento, controlando así el interlineado.

Valores

  • normal: Usa el interlineado estándar (valor por defecto).

  • number: Un número sin unidad que se multiplica por el tamaño de la fuente del elemento (por ejemplo, 1.5).

  • length: Un valor fijo en unidades como px, em, cm, etc. (por ejemplo, 20px).

  • percentage: Un porcentaje del tamaño de la fuente del elemento (por ejemplo, 150%).

  • inherit: Hereda el valor del elemento padrehttps://developer.mozilla.org/es/docs/Web/CSS/line-height.

Ejemplos de uso

1.5 veces el tamaño de la fuente:

p {
  line-height: 1.5;
}

120% del tamaño de la fuente:

h1 {
  line-height: 120%;
}

20 píxeles de altura de línea:

div {
  line-height: 20px;
}

Ejemplo de animación:

.animated-text {
  font-size: 20px;
  animation: lineHeightAnimation 3s infinite alternate;
}

@keyframes lineHeightAnimation {
  0% {
    line-height: 1;
  }
  100% {
    line-height: 2;
  }
}

En este ejemplo, el line-height de un párrafo con la clase animated-text cambiará continuamente entre 1 y 2.
