Propiedad font-size

La propiedad font-size en CSS se utiliza para especificar el tamaño de la fuente del texto en un elemento HTML.

Sintaxis básica:

selector {
  font-size: valor;
}

Posibles valores de font-size:

  • Palabras clave absolutas: xx-small, x-small, small, medium, large, x-large, xx-large.

  • Palabras clave relativas: larger, smaller.

  • Unidades de longitud: px (píxeles), em, rem, pt (puntos), cm (centímetros), etc.

  • Porcentajes: Un porcentaje relativo al tamaño de la fuente del elemento padre.

Ejemplos

Tamaño de la tipografía en píxeles:

p {
  font-size: 16px;
}

Dos veces el tamaño de la tipografía del elemento padre:

h1 {
  font-size: 2em;
}

150% del tamaño de la tipografía del elemento padre:

div {
  font-size: 150%;
}

Consideraciones

  • Unidades relativas: em y rem son unidades relativas. em se basa en el tamaño de la fuente del elemento padre, mientras que rem se basa en el tamaño de la fuente del elemento raíz (generalmente <html>).

  • Accesibilidad: Usar unidades relativas como em y rem puede mejorar la accesibilidad, ya que permite que el tamaño de la fuente se ajuste según las preferencias del usuario.

Ejemplos con unidades relativas

Tamaño base:

body {
  font-size: 16px;
}

Dos veces el tamaño de la fuente del elemento raíz:

h2 {
  font-size: 2rem;
}

1.5 veces el tamaño de la fuente del elemento padre:

p {
  font-size: 1.5em;
}
