Propiedad text-overflow

La propiedad text-overflow de CSS se utiliza para especificar cómo se debe mostrar el texto que desborda su contenedor. Esta propiedad es útil cuando el contenido de texto es más largo que el área disponible y necesitas indicar visualmente que hay más texto oculto. Aquí tienes un resumen de sus valores y usos:

Sintaxis

text-overflow: clip | ellipsis | string;

Valores

  • clip: Este es el valor predeterminado. El texto que desborda se corta sin ninguna indicación visual.

  • ellipsis: Muestra una elipsis (...) para representar el texto que no se muestra.

  • string: Permite especificar una cadena de texto personalizada para representar el contenido desbordado (este valor es experimental y puede no estar soportado en todos los navegadores).

Ejemplos

Texto cortado:

div {
  white-space: nowrap;
  overflow: hidden;
  text-overflow: clip;
}

En este ejemplo, el texto que desborda se corta sin ninguna indicación visual.

Texto con elipsis:

div {
  white-space: nowrap;
  overflow: hidden;
  text-overflow: ellipsis;
}

Aquí, el texto que desborda se muestra con una elipsis (...) para indicar que hay más contenido.
