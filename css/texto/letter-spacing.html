Propiedad letter-spacing

La propiedad letter-spacing en CSS se utiliza para ajustar el espacio entre los caracteres de un texto.

Se pueden usar como valores normal, que es el valor por defecto y deja que el navegador determine el espaciado óptimo entre las letras o especificar una longitud para aumentar o disminuir el espacio entre caracteres. Esta longitud puede ser positiva o negativa y se puede expresar en unidades como px, em, pt, etc.

Ejemplos

Aumenta el espacio entre letras:

p {
  letter-spacing: 2px;
}

Disminuir el espacio entre letras:

h1 {
  letter-spacing: -1px; /*  */
}

La propiedad letter-spacing es heredada, lo que significa que los elementos hijos pueden heredar el valor de esta propiedad de su elemento padre.
