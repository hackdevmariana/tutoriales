Propiedad text-decoration

La propiedad text-decoration en CSS se utiliza para aplicar decoraciones al texto, como subrayado, tachado, y más.

Principales características

  • text-decoration-line: Define el tipo de decoración. Puede ser:

    • none: Sin decoración.

    • underline: Subrayado.

    • overline: Línea sobre el texto.

    • line-through: Línea a través del texto (tachado).

    • blink: Parpadeo (aunque no es ampliamente soportado).

    • text-decoration-style: Define el estilo de la línea de decoración. Puede ser:

    • solid: Línea sólida.

    • double: Línea doble.

    • dotted: Línea punteada.

    • dashed: Línea discontinua.

    • wavy: Línea ondulada.

  • text-decoration-color: Define el color de la decoración. Puede ser cualquier valor de color válido en CSS.

  • text-decoration-thickness: Define el grosor de la línea de decoración (CSS Text Decoration Level 4).

Ejemplo

p {
  text-decoration: underline wavy red;
}

Este código aplicará un subrayado ondulado y rojo al texto dentro de un párrafo
