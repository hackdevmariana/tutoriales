Propiedad unicode-bidi

La propiedad unicode-bidi de CSS se utiliza junto con la propiedad direction para controlar cómo se maneja el texto bidireccional en un documento. Esto es especialmente útil cuando se mezclan idiomas que se escriben de izquierda a derecha (LTR) con idiomas que se escriben de derecha a izquierda (RTL).

Valores

  • normal: Este es el valor por defecto. No se abre un nivel adicional de incrustación.

  • embed: Abre un nivel adicional de incrustación para elementos en línea, respetando la dirección especificada.

  • bidi-override: Crea una anulación para elementos en línea y para elementos de contenedor de bloque, ignorando la parte implícita del algoritmo bidireccional.

  • isolate: Aísla el elemento de sus hermanos, calculando la direccionalidad del contenedor sin considerar el contenido del elemento.

  • isolate-override: Combina el comportamiento de aislamiento con la anulación de bidi-override.

  • plaintext: Calcula la direccionalidad del elemento sin considerar el estado bidireccional del padre o el valor de la propiedad direction.

Ejemplo

div {
  direction: rtl;
  unicode-bidi: bidi-override;
}

En este ejemplo, el texto dentro del div se mostrará de derecha a izquierda, y cualquier reordenamiento implícito del texto será ignorado.
