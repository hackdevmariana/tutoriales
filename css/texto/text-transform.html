Propiedad text-transform

La propiedad text-transform en CSS se utiliza para controlar la capitalización del texto en un elemento.

Principales valores

  • none: No aplica ninguna transformación al texto. Este es el valor por defecto.

  • capitalize: Convierte la primera letra de cada palabra a mayúscula.

  • uppercase: Convierte todas las letras del texto a mayúsculas.

  • lowercase: Convierte todas las letras del texto a minúsculas.

  • full-width: Convierte los caracteres a su forma de ancho completo, comúnmente usado en tipografías asiáticas.

Ejemplos de uso

Texto en mayúsculas:

p.uppercase {
  text-transform: uppercase;
}

Texto en minúsculas

p.lowercase {
  text-transform: lowercase;
}

Capitalizar cada palabra

p.capitalize {
  text-transform: capitalize;
}
