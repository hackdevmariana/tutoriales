Propiedad word-break

La propiedad word-break en CSS se utiliza para especificar cómo deben romperse las palabras cuando alcanzan el final de una línea. Esto es especialmente útil para manejar palabras largas o URLs que podrían desbordar el contenedor.

Valores de word-break

  • normal: Usa las reglas de quiebre de línea por defecto.

  • break-all: Permite que las palabras se rompan en cualquier carácter para evitar el desbordamiento.

  • keep-all: Evita los quiebres de palabras en texto en chino, japonés o coreano (CJK). Para texto no CJK, el comportamiento es el mismo que normal.

  • break-word: Este valor está deprecado, pero se comporta de manera similar a overflow-wrap: anywhere, permitiendo que las palabras se rompan en cualquier punto para evitar el desbordamiento.

Ejemplo de uso

.long-word {
  word-break: break-all;
}
