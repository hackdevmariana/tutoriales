Propiedad font-family

La propiedad font-family en CSS se utiliza para especificar una lista de fuentes que se aplicarán a un elemento. Esta lista se define en orden de prioridad, de modo que si la primera fuente no está disponible, el navegador intentará usar la siguiente, y así sucesivamente.

Sintaxis básica:

selector {
  font-family: "Nombre de Fuente", nombre-genérico;
}

Ejemplo:

body {
  font-family: "Arial", sans-serif;
}

h1 {
  font-family: "Times New Roman", serif;
}

Tipos de tipografías

  • Nombres de fuentes específicas: Como "Arial", "Times New Roman", "Courier New", etc. Si el nombre de la fuente contiene espacios, debe estar entre comillas.

  • Nombres genéricos: Como serif, sans-serif, monospace, cursive, fantasy. Estos nombres no necesitan comillas y se utilizan como respaldo en caso de que las fuentes específicas no estén disponibles.

Ejemplo con varias tipografías

p {
  font-family: "Gill Sans", "Gill Sans MT", Calibri, sans-serif;
}

En este ejemplo, el navegador intentará usar "Gill Sans". Si no está disponible, probará "Gill Sans MT", luego "Calibri", y finalmente cualquier fuente sans-serif disponible en el sistema
