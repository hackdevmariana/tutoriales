Propiedad text-align

La propiedad text-align en CSS se utiliza para establecer la alineación horizontal del contenido de texto dentro de un elemento de bloque o una celda de tabla.

Principales valores

  • left: Alinea el texto a la izquierda.

  • right: Alinea el texto a la derecha.

  • center: Centra el texto.

  • justify: Justifica el texto, es decir, alinea el texto tanto a la izquierda como a la derecha, ajustando el espacio entre palabras para que las líneas tengan la misma longitud.

  • start: Alinea el texto al inicio del contenedor, dependiendo de la dirección del texto (izquierda para LTR, derecha para RTL).

  • end: Alinea el texto al final del contenedor, dependiendo de la dirección del texto (derecha para LTR, izquierda para RTL).

Ejemplo de uso

Este código centrará el texto dentro de los párrafos:

p {
  text-align: center;
}

Justificar texto:

p {
  text-align: justify;
}

Además, hay propiedades relacionadas como text-align-last, que especifica cómo alinear la última línea de un texto, y direction, que establece la dirección del texto (LTR o RTL) y puede influir en la alineación.
