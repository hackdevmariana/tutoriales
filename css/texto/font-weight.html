Propiedad font-weight

La propiedad font-weight en CSS se utiliza para especificar el grosor o peso de la fuente de un elemento de texto.

Esta propiedad permite controlar la apariencia visual del texto, lo que puede influir significativamente en la jerarquía y legibilidad del contenido en una página web.

Sintaxis básica

selector {
  font-weight: valor;
}

Valores aceptados por font-weight:

  • Palabras clave:

    • normal: Peso normal de la fuente (equivalente a 400).

    • bold: Negrita (equivalente a 700).

    • lighter: Un peso más ligero que el del elemento padre.

    • bolder: Un peso más grueso que el del elemento padre.

  • Valores numéricos: De 100 a 900 en incrementos de 100. Estos valores permiten una mayor flexibilidad en el grosor de la fuente.

    • 100: Muy delgado.

    • 200, 300, 400 (normal), 500, 600, 700 (bold), 800, 900: Muy grueso.

Ejemplos

Peso normal:

p {
  font-weight: normal;
}

Negrita:

h1 {
  font-weight: bold;
}

Peso ligero:

span {
  font-weight: 300;
}

Muy grueso:

div {
  font-weight: 900;
}

Consideraciones

  • Compatibilidad: No todas las fuentes soportan todos los valores de peso. Algunas fuentes solo están disponibles en normal y bold.

  • Heredabilidad: La propiedad font-weight es heredable, lo que significa que los elementos hijos pueden heredar el valor del elemento padre.

Ejemplo con herencia

Peso medio:

body {
  font-weight: 500;
}

Hereda el peso del elemento padre (body):

h2 {
  font-weight: inherit;
}

La propiedad font-weight es esencial para el diseño tipográfico en la web, permitiendo destacar o suavizar el texto según sea necesario.
