Propiedad white-space

La propiedad white-space en CSS se utiliza para controlar cómo se maneja el espacio en blanco dentro de un elemento. Esto incluye espacios, tabulaciones y caracteres de nueva línea.

Valores

  • normal: Los espacios en blanco se colapsan en un solo espacio. El texto se ajusta automáticamente a las líneas según sea necesario.

  • nowrap: Los espacios en blanco se colapsan en un solo espacio, pero el texto no se ajusta a nuevas líneas. Continúa en la misma línea hasta que se encuentre una etiqueta
    .

  • pre: Los espacios en blanco se preservan. El texto solo se ajusta en los saltos de línea y actúa como la etiqueta <pre> en HTML.

  • pre-wrap: Los espacios en blanco se preservan, y el texto se ajusta a las líneas según sea necesario y en los saltos de línea.

  • pre-line: Los espacios en blanco se colapsan en un solo espacio, pero el texto se ajusta a las líneas según sea necesario y en los saltos de línea.

  • break-spaces: Similar a pre-wrap, pero cualquier secuencia de espacios en blanco preservados siempre ocupa espacio, incluyendo al final de la línea. Se permite un salto de línea después de cada carácter de espacio preservado.

Ejemplos

.normal {
  white-space: normal;
}

.nowrap {
  white-space: nowrap;
}

.pre {
  white-space: pre;
}

.pre-wrap {
  white-space: pre-wrap;
}

.pre-line {
  white-space: pre-line;
}

.break-spaces {
  white-space: break-spaces;
}
