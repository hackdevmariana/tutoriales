Saber repositorio remoto de un proyecto git

Para saber el repositorio remoto de un proyecto git, podemos ejecutar desde el directorio del proyecto:

git remote -v

Este comando mostrará las URL de los repositorios remotos asociados con el proyecto local.

Si no está asociado a un repositorio, no devolverá nada. Si está a sociado a un repositorio remoto, debería mostrar algo como esto:

origin  https://github.com/usuario/nombre-del-repositorio.git (fetch)
origin  https://github.com/usuario/nombre-del-repositorio.git (push)
