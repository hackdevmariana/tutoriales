Trabajar con cadenas de texto en PHP

PHP ofrece una amplia variedad de funciones para manipular y gestionar cadenas de texto.

Veamos algunas de las más importantes:

Tipos de cadenas en PHP

Comillas Simples (' '): Las cadenas delimitadas por comillas simples no interpretan variables ni secuencias de escape especiales (excepto la barra invertida \ y la comilla simple ').

$cadena = 'Esto es una cadena simple';

Comillas Dobles (" "): Las cadenas delimitadas por comillas dobles interpretan variables y secuencias de escape como \n (nueva línea) y \t (tabulador).

$nombre = "Juan";
$cadena = "Hola, $nombre";

Heredoc: Permite definir cadenas de múltiples líneas que pueden contener variables.

$cadena = <<<EOD
Esto es una cadena
de múltiples líneas
EOD;

Nowdoc: Similar a Heredoc, pero no interpreta variables.

$cadena = <<<'EOD'
Esto es una cadena
de múltiples líneas
EOD;

Principales funciones para manipular cadenas

  • strlen(): Devuelve la longitud de una cadena.
$longitud = strlen("Hola Mundo");

$longitud almacena 10

  • strtolower() y strtoupper(): Convierte una cadena a minúsculas o mayúsculas, respectivamente.
$minusculas = strtolower("HOLA MUNDO");
$mayusculas = strtoupper("hola mundo");

$minusculas y $mayusculas almacenan "hola mundo" y "HOLA MUNDO", respectivamente.

  • substr(): Devuelve una parte de una cadena.
$parte = substr("Hola Mundo", 0, 4);

$parte almacena "Hola"

  • strpos(): Encuentra la posición de la primera aparición de un substring en una cadena.
$posicion = strpos("Hola Mundo", "Mundo");

$posicion almacena 5

  • str_replace(): Reemplaza todas las apariciones de un substring dentro de una cadena.
$nueva_cadena = str_replace("Mundo", "PHP", "Hola Mundo");

$nueva_cadena almacena "Hola PHP"

  • explode(): Divide una cadena en un array usando un delimitador.
$array = explode(" ", "Hola Mundo PHP"); // ["Hola", "Mundo", "PHP"]

$array almacena ["Hola", "Mundo", "PHP"]

  • implode(): Une elementos de un array en una cadena.
$cadena = implode("-", ["Hola", "Mundo", "PHP"]); // "Hola-Mundo-PHP"

$cadena almacena "Hola-Mundo-PHP"
