Usar código de ficheros externos

Incluir ficheros externos en PHP es una práctica común para organizar y reutilizar código.

En PHP tenemos los comandos include, include_once, require y require_once para incluir ficheros externos.

Veamos sus diferencias.

include

El comando include se utiliza para incluir y evaluar un fichero. Si el fichero no se encuentra, PHP emitirá una advertencia (warning) pero continuará ejecutando el script.

include 'header.php';

require

El comando require es similar a include, pero si el fichero no se encuentra, PHP emitirá un error fatal y detendrá la ejecución del script.

require 'config.php';

include_once

include_once funciona igual que include, pero asegura que el fichero sólo se incluya una vez, incluso si se llama varias veces en el mismo script. Esto es útil para evitar redefiniciones de funciones o clases.

include_once 'functions.php';

require_once

require_once es similar a require, pero también asegura que el fichero sólo se incluya una vez. Es útil para archivos críticos que no deben ser incluidos más de una vez.

require_once 'database.php';
