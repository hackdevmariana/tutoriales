Generar un número aleatorio

Podemos generar un número aleatorio en PHP con la función rand() o mt_rand().

Usando rand()

<?php
  $numero_aleatorio = rand(0, 100);
  echo $numero_aleatorio;
?>

Usando mt_rand()

mt_rand() es una alternativa más rápida y con mejor distribución de números aleatorios:

<?php
  $numero_aleatorio = mt_rand(0, 100);
  echo $numero_aleatorio;
?>

Generar un número aleatorio de punto flotante

Para generar un número aleatorio de punto flotante, podemos combinar rand() con una división:

<?php
  $numero_aleatorio = rand(0, 100) / 100;
  echo $numero_aleatorio;
?>
