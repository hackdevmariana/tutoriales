Comprimir y descomprimir ficheros rar

Para comprimir y descomprimir ficheros rar, tenemos el comando unrar. En caso de no tenerlo instalado, podemos instalarlo con:

sudo apt-get install unrar

Descomprimir

Descomprimir un fichero rar en el directorio actual:

unrar x fichero.rar

Descomprimir un fichero rar especificando el directorio donde se descomprimirá el fichero:

unrar x fichero.rar /ruta/al/directorio

Comprimir

Para comprimir un fichero en rar, podemos hacerlo con el siguiente comando:

rar a fichero.rar nombre_del_fichero

Podemos utilizar opciones adicionales para personalizar la compresión:

  • -p : Agrega una contraseña al fichero comprimido.

  • -m0 : Utiliza el nivel de compresión máximo.

  • -r : Comprime recursivamente los ficheros en un directorio.

  • -v : Divide el fichero en volúmenes de tamaño especificado (por ejemplo, -v100M para volúmenes de 100 MB).

Por ejemplo, para comprimir un directorio con máxima compresión y protección por contraseña:

rar a -p -m0 -r nombre_del_fichero.rar /ruta/al/directorio
