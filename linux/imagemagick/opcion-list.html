Opción -list en ImageMagick

La opción -list en ImageMagick se utiliza para mostrar información detallada sobre las capacidades y configuraciones del software.

Podemos usarla para listar varios aspectos, como formatos de imagen, filtros, colores, y más.

Veamos algunos ejemplos de cómo usar -list:

Listar formatos de imagen soportados

magick -list format

O:

convert -list format

Esto mostrará una lista de todos los formatos de imagen que ImageMagick puede manejar.

Listar filtros disponibles

magick -list filter

O:

convert -list filter

Esto mostrará una lista de todos los filtros que ImageMagick puede aplicar a las imágenes.

Listar colores disponibles

magick -list color

O:

convert -list color

Esto mostrará una lista de todos los colores disponibles en ImageMagick.

Listar elementos listables disponibles

magick -list list

O:

convert -list list

Esto mostrará una lista de todos los elementos disponibles en ImageMagick.

Listar las alineaciones disponibles

magick -list align

O:

convert -list align

La opción -list align en ImageMagick lista los alineamientos posibles que se pueden usar en diversas operaciones.

Center: Centra el texto o la imagen dentro del área especificada.

End: Alinea el texto o la imagen al final del área especificada.

Left: Alinea el texto o la imagen a la izquierda del área especificada.

Middle: Alinea el texto o la imagen al medio del área especificada.

Right: Alinea el texto o la imagen a la derecha del área especificada.

Start: Alinea el texto o la imagen al inicio del área especificada.

Listar los gradientes disponibles

magick -list gradient

O:

convert -list gradient
