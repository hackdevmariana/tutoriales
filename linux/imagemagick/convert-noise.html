Opción -noise de convert

La opción -noise en convert de ImageMagick se utiliza para añadir ruido a una imagen.

Este ruido puede ser útil para efectos creativos, simulación de texturas o incluso para pruebas de procesamiento de imágenes.

Sintaxis

convert imagen.jpg -noise tipo_ruido imagen_con_ruido.jpg

Tipos de ruido

ImageMagick permite aplicar diferentes tipos de ruido, dependiendo del efecto deseado:

  • Uniform: Añade ruido uniforme a la imagen.

  • Gaussian: Aplica ruido con una distribución gaussiana (normal).

  • Multiplicative: Introduce ruido multiplicativo.

  • Impulse: Genera ruido de tipo "sal y pimienta" (píxeles blancos y negros aleatorios).

  • Laplacian: Aplica ruido basado en una distribución laplaciana.

  • Poisson: Añade ruido basado en una distribución de Poisson.

Listar tipos de ruido

convert -list noise

Ejemplo de uso

convert imagen.jpg -noise Gaussian imagen_con_ruido.jpg

Podemos modificar la intensidad con -attenuate:

convert imagen.jpg -attenuate 0.5 -noise Gaussian imagen_con_ruido.jpg

En este caso, -attenuate reduce la intensidad del ruido aplicado.
