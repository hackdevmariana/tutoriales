Crear una imagen con un texto ajustando tamaño de la tipografía o del lienzo

Ajustar el lienzo al tamaño del texto

El parámetro pointsize define el tamaño de la fuente del texto en puntos. Si especificamos pointsize sin definir size, ImageMagick creará un lienzo del tamaño necesario para ajustar el texto según el tamaño de la fuente especificada.

convert -pointsize 48 -fill black -gravity center -annotate 0 "Hola, mundo!" output.png

En este caso, ImageMagick generará una imagen que contenga el texto "Hola, mundo!" centrado, utilizando una fuente de 48 puntos. El tamaño del lienzo se ajustará automáticamente para encajar el texto.

Ajustar el tamaño del texto al tamaño del lienzo

El parámetro size define las dimensiones del lienzo en píxeles. Si especificamos size sin definir pointsize, ImageMagick creará un lienzo del tamaño especificado y utilizará un tamaño de fuente predeterminado para el texto.

convert -size 800x600 xc:white -fill black -gravity center -annotate 0 "Hola, mundo!" output.png

En este caso, se creará un lienzo de 800x600 píxeles con un fondo blanco, y el texto "Hola, mundo!" se centrará en el lienzo utilizando el tamaño de fuente predeterminado.

Comparación

  • pointsize sin size: ImageMagick ajusta el tamaño del lienzo para encajar el texto con el tamaño de fuente especificado.

size sin pointsize: ImageMagick crea un lienzo de las dimensiones especificadas y usa el tamaño de fuente predeterminado.

Combinación de pointsize y size

Para tener un control total sobre el tamaño del lienzo y el tamaño de la fuente del texto, puedes especificar ambos parámetros juntos:

convert -size 800x600 xc:white -pointsize 48 -fill black -gravity center -annotate 0 "Hola, mundo!" output.png

En este ejemplo, se crea un lienzo de 800x600 píxeles con una fuente de 48 puntos.
