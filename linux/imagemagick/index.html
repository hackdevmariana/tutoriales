ImageMagick

ImageMagick es una suite de software libre y de código abierto para mostrar, convertir y editar archivos de imágenes raster e imágenes vectoriales.

ImageMagick soporta más de 200 formatos de archivo de imagen, incluyendo JPEG, PNG, GIF, TIFF, y Ultra HDR.

Puede realizar diversas operaciones de manipulación de imágenes como el redimensionamiento, recorte, corrección del color, y más.

Ofrece una interfaz de línea de comandos para ejecutar tareas complejas de procesamiento de imágenes. También incluye APIs para integrar sus características en aplicaciones de software, disponibles en varios lenguajes como C, C++, Perl, y otros.

Permite la creación de pipelines de manipulación de imágenes que pueden ejecutarse automáticamente, sin intervención manual.

Comandos

convert

Convierte imágenes de un formato a otro y aplica varias transformaciones de imagen.

Cambiar formato:

convert input.jpg output.png

Escalar imagen:

convert input.jpg -resize 50% output.jpg

mogrify

Modifica imágenes existentes en su lugar, sobreescribiéndolas, aplicando transformaciones como redimensionamiento, rotación, etc.

Ejemplo:

mogrify -resize 800x800 *.jpg

identify

Muestra información sobre las imágenes recibidas como parámetros.

Ejemplo:

identify input.jpg

Más sobre identify

composite

Superpone una imagen sobre otra.

Ejemplo:

composite overlay.png input.jpg output.jpg

Más sobre composite

montage

Crea una composición de imágenes en una sola.

Ejemplo:

montage image1.jpg image2.jpg image3.jpg montage.jpg

Más sobre montage

Ejemplos de uso

Convertir a jpg con una calidad del 80% y redimensionar al 50%:

convert input.jpg -resize 50% -quality 80 output.jpg

Añadir texto a una imagen:

convert input.jpg -pointsize 24 -fill white -annotate +10+50 "Hola, mundo" output.jpg

Crear una miniatura de una imagen:

convert input.jpg -thumbnail 200x200 thumbnail.jpg

Aplicar filtro de efecto sepia:

convert input.jpg -sepia-tone 80% output.jpg

Uso de imagemagick en script de bash

ImageMagick se puede utilizar en scripts Bash para procesar imágenes en lote.

Un ejemplo de script Bash que redimensiona todas las imágenes en un directorio:

#!/bin/bash

input_dir="path_to_input_directory"
output_dir="path_to_output_directory"

mkdir -p "$output_dir"

for file in "$input_dir"/*.jpg; do
  filename=$(basename "$file")
  convert "$file" -resize 800x800 "$output_dir/$filename"
done

echo "Todas las imágenes han sido redimensionadas."
