Opción -adaptive-resize en convert

El modificador -adaptive-resize en el comando convert de ImageMagick se utiliza para redimensionar una imagen de manera que se ajuste automáticamente el tamaño según el contenido de la imagen.

Esto significa que el algoritmo de redimensionamiento ajusta el tamaño de la imagen para mantener la calidad y evitar la distorsión, especialmente en áreas con mucho detalle.

Ejemplo de uso

convert entrada.jpg -adaptive-resize 800x600 salida.jpg

En este comando, entrada.jpg es el archivo de imagen original, 800x600 es el tamaño deseado (ancho x alto), y salida.jpg es el archivo de imagen resultante con el tamaño ajustado.

El uso de -adaptive-resize es especialmente útil cuando necesitamos redimensionar imágenes que tienen áreas con diferentes niveles de detalle, ya que ayuda a mantener la calidad visual en toda la imagen.
