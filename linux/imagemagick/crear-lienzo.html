Crear un lienzo de un color uniforme con ImageMagick

Para crear un lienzo de un color uniforme con ImageMagick, podemos usar el comando convert, indicándole el tamaño y el nombre del fichero a generar.

convert -size 500x500 xc:PaleGreen image_01.png

Para ver los colores disponibles en ImageMagick, podemos usar:

convert -list color

O indicarle un código hexadecimal:

convert -size 500x500 xc:#ff0000 image_02.png
