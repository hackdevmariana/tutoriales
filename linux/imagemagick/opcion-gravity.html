Opción -gravity

El comando -gravity en ImageMagick se utiliza para especificar la posición de la imagen dentro del área de salida.

Esto es útil cuando queremos centrar, alinear o posicionar una imagen de una manera específica dentro de un lienzo.

Ejemplo básico

convert input.jpg -gravity center -extent 500x500 output.jpg

En este ejemplo, la imagen input.jpg se centra dentro de un marco de 500x500 píxeles y se guarda como output.jpg.

Usos de -gravity

Podemos usar -gravity para alinear texto dentro de una imagen.

Por ejemplo, para centrar texto en una imagen:

convert input.jpg -gravity center -pointsize 20 -fill white -annotate +0+0 'Texto centrado' output.jpg

Crear un borde alrededor de una imagen y centrar la imagen original dentro de ese borde:

convert input.jpg -gravity center -background black -extent 600x600 output.jpg

Para colocar una imagen en una posición específica dentro de otra imagen:

convert background.jpg overlay.png -gravity northwest -geometry +10+10 -composite output.jpg

Podemos usar -gravity en combinación con el comando -crop para recortar una imagen desde un punto específico:

convert input.jpg -gravity center -crop 200x200+0+0 +repage output.jpg

Opciones de -gravity

  • Northwest: Esquina superior izquierda

  • North: Centro horizontal superior

  • Northeast: Esquina superior derecha

  • West: Centro vertical izquierdo

  • Center: Centro

  • East: Centro vertical derecho

  • Southwest: Esquina inferior izquierda

  • South: Centro horizontal inferior

  • Southeast: Esquina inferior derecha

Ejemplo complejo

Podemos combinar -gravity múltiples veces en una misma instrución.

Podemos crear una imagen con un borde negro, colocar una marca de agua en la esquina inferior derecha y añadir texto centrado:

convert input.jpg -gravity center -background black -extent 600x600 \
-gravity southeast -draw "image Over 0,0 0,0 'watermark.png'" \
-gravity center -pointsize 20 -fill white -annotate +0+0 'Texto centrado' output.jpg
