Comando identify

El comando identify de ImageMagick es una utilidad de línea de comandos que describe el formato y las características de uno o más archivos de imagen.

Es especialmente útil para obtener información detallada sobre las propiedades de una imagen sin necesidad de abrirla en un editor gráfico.

Uso básico

Para usar identify, simplemente necesitamos especificar la ruta del archivo de imagen que deseamos analizar.

Por ejemplo:

magick identify rose.jpg

Esto proporcionará información básica como el formato de la imagen, las dimensiones, el espacio de color, y el tamaño del archivo.

Uso detallado

Si necesitamos información más detallada, podemos usar la opción -verbose:

magick identify -verbose rose.jpg

Esto dará una descripción completa de la imagen, incluyendo detalles como el tipo MIME, la geometría, el tipo de color, y estadísticas de canal.

Sin verbose:

Aplicaciones

El comando identify es útil para:

Análisis de imágenes en lote: Ideal para trabajar con grandes conjuntos de imágenes donde la revisión manual sería tediosa.

Organización y catalogación: Ayuda a extraer dimensiones y otros datos importantes para la gestión de colecciones de imágenes.

Automatización de tareas: Puede ser usado en scripts para procesar imágenes automáticamente.
