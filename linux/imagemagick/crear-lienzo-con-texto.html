Crear una imagen con un texto con ImageMagick

El comando básico para crear una imagen con texto es convert.

Vamos a crear una imagen de 800x600 píxeles con un fondo blanco y un texto centrado en color negro:

convert -size 800x600 xc:white -gravity center -fill black -pointsize 48 -annotate 0 "Hola, mundo!" output.png

Explicación de los parámetros

-size 800x600: Define el tamaño de la imagen.

xc:white: Establece el color de fondo de la imagen (en este caso, blanco).

-gravity center: Centra el texto en la imagen.

-fill black: Establece el color del texto (en este caso, negro).

-pointsize 48: Define el tamaño de la fuente del texto.

-annotate 0 "Hola, mundo!": Añade el texto "Hola, mundo!" a la imagen.

output.png: Define el nombre del archivo de salida.

Personalización

Podemos cambiar la tipografía del texto usando el parámetro -font seguido de la ruta a la tipografía:

convert -size 800x600 xc:white -gravity center -fill black -font /path/to/font.ttf -pointsize 48 -annotate 0 "Hola, mundo!" output.png

Podemos añadir bordes y sombras al texto:

convert -size 800x600 xc:white -gravity center -fill black -stroke gray -strokewidth 1 -pointsize 48 -annotate 0 "Hola, mundo!" output.png

-stroke gray: Añade un borde gris alrededor del texto.

-strokewidth 1: Define el grosor del borde.
