Listar las tablas de una base de datos que contienen un determinado campo

Supongamos que tenemos una base de datos que se llama 'my_database' en la que sabemos que hay un campo con un determinado nombre, por ejemplo, 'my_field' pero no sabemos en qué tabla está.

Para encontrar las tablas en las que está ese determinado campo, podemos hacer:

SELECT table_name
FROM information_schema.columns
WHERE column_name = 'my_field'
AND table_schema = 'my_database';

Y nos devolverá las tablas en las que está ese campo buscado.
