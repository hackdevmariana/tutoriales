Listar ordenados los datos de una tabla de una base de datos

Podemos listar los datos de una tabla de una base de datos con:

SELECT * FROM nombre_de_la_tabla;

Si lo que queremos es mostrar esos datos ordenados, podemos usar la cláusula ORDER BY.

Ejemplos de uso

Ordenar por una columna específica en orden ascendente:

SELECT * FROM nombre_de_la_tabla
ORDER BY column_name ASC;

Ordenar por una columna específica en orden descendente:

SELECT * FROM nombre_de_la_tabla
ORDER BY column_name DESC;

Ordenar por múltiples columnas:

SELECT * FROM nombre_de_la_tabla
ORDER BY column1 ASC, column2 DESC;

Reemplazaremos column_name, column1, y column2 con los nombres de las columnas por las que queramos ordenar.
