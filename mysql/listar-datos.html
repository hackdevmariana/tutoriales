Listar los datos de una tabla de una base de datos

Para ver los datos almacenados en una tabla en MySQL desde la consola, debemos abrir la consola MySQL:

mysql -u tu_usuario -p

E ingresar la contraseña.

Luego, seleccionar la base de datos:

USE nombre_de_la_base_de_datos;

Y mostrar los datos de una tabla específica con:

SELECT * FROM nombre_de_la_tabla;
