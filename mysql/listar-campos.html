Listar los campos de una tabla de una base de datos MySQL

Para ver los campos (columnas) de una tabla en una base de datos MySQL desde la consola,primero debemos abrir la consola MySQL:

mysql -u usuario -p

Por ejemplo, para entrar como administrador de la base de datos, escribiremos:

mysql -u root -p

E ingresar la contraseña cuando la solicite mysql.

Después, seleccionamos la base de datos:

USE nombre_de_la_base_de_datos;

Si no sabemos el nombre la base de datos, podemos listar las bases de datos con:

SHOW DATABASES;

Mostrar las columnas de una tabla específica:

DESCRIBE nombre_de_la_tabla;

O:

SHOW COLUMNS FROM nombre_de_la_tabla;

Si no sabemos el nombre de la tabla, podemos listar las tablas de una base de datos con:

SHOW FULL TABLES FROM database;

Listar los campos que cumplan una determinada condición

Podemos indicar con la cláusula WHERE que, en lugar de listar todos los campos de la tabla, sólo se listen aquellos que cumplan una condición:

SELECT * FROM nombre_de_la_tabla WHERE campo="valor";
