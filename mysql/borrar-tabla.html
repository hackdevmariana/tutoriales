Borrar una tabla de una base de datos MySQL

Para borrar una tabla de una base de datos de MySQL desde la línea de comandos, debemos acceder a MySQL con:

mysql -u tu_usuario -p

Introducimos la contraseña.

Seleccionamos la base de datos que contiene la tabla que deseamos borrar:

USE nombre_de_tu_base_de_datos;

Y borramos la tabla usando el comando DROP TABLE:

DROP TABLE nombre_de_tu_tabla;
