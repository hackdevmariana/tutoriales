Crear una copia de una base de datos MySQL

Para crear una copia de una base de datos MySQL desde la consola, por ejemplo, para tener una copia de seguridad o para exportarla en otro servidor, podemos usar la siguiente instrucción:

mysqldump -u usuario -p nombre_de_base_datos > backup.sql

El comando mysqldump pedirá la contraseña y generará la copia de la base de datos completa, tanto la estructura como los datos almacenados.
