Eliminar los elementos de una lista que están presentes en otra lista

En Python, podemos eliminar los elementos de una lista que están presentes en otra lista mediante la comprensión de listas para que cree una nueva lista que contenga sólo los elementos de una lista que no estén en otra lista:

lista1 = [1, 2, 3, 4, 5]
lista2 = [2, 4]

resultado = [elemento for elemento in lista1 if elemento not in lista2]

print(resultado)

Este ejemplo devolverá [1, 3, 5].
