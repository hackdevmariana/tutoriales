Copiar el valor de una variable en el portapapeles

Para copiar el contenido de una variable al portapapeles en Python, podemos usar el módulo pyperclip.

Este módulo es multiplataforma y permite copiar y pegar texto en el portapapeles de manera sencilla.

Primero, instalamos el módulo pyperclip si aún no está instalado:

pip install pyperclip

Copiar el contenido al portapapeles:

import pyperclip

texto = "Hola, esto es un ejemplo."
pyperclip.copy(texto)

Pegar el contenido del portapapeles:

import pyperclip

contenido_portapapeles = pyperclip.paste()
print(contenido_portapapeles)

Script completo:

import pyperclip

texto = "Hola, esto es un ejemplo."
pyperclip.copy(texto)

contenido_portapapeles = pyperclip.paste()
print(contenido_portapapeles)

En este ejemplo, el texto "Hola, esto es un ejemplo." se copia al portapapeles y luego se verifica pegándolo de nuevo
