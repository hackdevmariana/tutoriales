Reemplazar subcadena

Para reemplazar una subcadena por otra en Python, podemos usar el método replace(). Este método permite reemplazar todas las ocurrencias de una subcadena específica dentro de una cadena por otra subcadena.

Ejemplo básico

cadena = "Me gustan las manzanas"
nueva_cadena = cadena.replace("manzanas", "peras")
print(nueva_cadena)

En este ejemplo, la subcadena "manzanas" se reemplaza por "peras".

El método replace() también permite especificar el número de reemplazos que queremos realizar usando un tercer parámetro opcional count.

Por ejemplo:

cadena = "manzana, manzana, manzana"
nueva_cadena = cadena.replace("manzana", "pera", 2)
print(nueva_cadena)

En este caso, sólo se reemplazan las dos primeras ocurrencias de "manzana".
