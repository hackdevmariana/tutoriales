Comandos más habituales de laravel-modules

El paquete nwidart/laravel-modules proporciona una serie de comandos Artisan que simplifican el desarrollo de módulos en Laravel. Estos comandos ayudan a generar estructuras completas y automatizan tareas comunes, lo que facilita la creación de controladores, modelos, migraciones, rutas, entre otros.

Aquí tenemos una lista de los comandos más importantes y útiles que nwidart/laravel-modules ofrece para facilitar el desarrollo modular:

Comandos generales

Crear un nuevo módulo:

php artisan module:make <module-name>

Crea un nuevo módulo con la estructura básica (controladores, rutas, vistas, etc.).

Listar todos los módulos:

php artisan module:list

Muestra una lista de todos los módulos disponibles en tu proyecto.

Habilitar un módulo:

php artisan module:enable <module-name>

Habilita un módulo específico.

Deshabilitar un módulo:

php artisan module:disable <module-name>

Deshabilita un módulo específico.

Eliminar un módulo:

php artisan module:delete <module-name>

Elimina completamente un módulo de tu proyecto.

Publicar recursos de un módulo:

php artisan module:publish <module-name>

Publica los recursos del módulo (como configuraciones, vistas, etc.).

Cargar todos los módulos:

php artisan module:publish-config

Publica los archivos de configuración de todos los módulos.

Comandos de generación

nwidart/laravel-modules también ofrece comandos específicos para generar componentes dentro de los módulos.

Generar un controlador:

php artisan module:make-controller <controller-name> <module-name>

Crea un nuevo controlador dentro del módulo especificado.

Generar un modelo:

php artisan module:make-model <model-name> <module-name>

Crea un nuevo modelo dentro del módulo.

Generar una migración:

php artisan module:make-migration <migration-name> <module-name>

Crea una migración dentro del módulo.

Generar una vista:

php artisan module:make-view <view-name> <module-name>

Crea una nueva vista dentro del módulo.

Generar un middleware:

php artisan module:make-middleware <middleware-name> <module-name>

Crea un nuevo middleware dentro del módulo.

Generar una seed (datos de prueba):

php artisan module:make-seed <seed-name> <module-name>

Crea un nuevo archivo de seed para poblar la base de datos con datos de prueba.

Generar una clase de evento:

php artisan module:make-event <event-name> <module-name>

Crea un evento dentro del módulo.

Generar una clase de listener:

php artisan module:make-listener <listener-name> <module-name>

Crea un listener asociado a un evento dentro del módulo.

Generar una clase de job:

php artisan module:make-job <job-name> <module-name>

Crea un job dentro del módulo.

Generar una clase de política (policy):

php artisan module:make-policy <policy-name> <module-name>

Crea una clase de política para manejar la autorización dentro del módulo.

Generar una clase de proveedor de servicios:

php artisan module:make-provider <provider-name> <module-name>

Crea un proveedor de servicios dentro del módulo.

Comandos para configuración y mantenimiento

Crear archivo de configuración para un módulo:

php artisan module:make-config <config-name> <module-name>

Crea un archivo de configuración dentro del módulo.

Crear archivo de traducción:

php artisan module:make-translation <lang-file> <module-name>

Crea un archivo de traducción para manejar varios idiomas dentro del módulo.

Generar rutas personalizadas para un módulo:

php artisan module:make-route <route-name> <module-name>

Crea un archivo de rutas personalizado dentro del módulo.

Otros comandos útiles

Migrar las tablas de un módulo:

php artisan module:migrate <module-name>

Ejecuta las migraciones de un módulo específico.

Migrar todas las tablas de todos los módulos:

php artisan module:migrate

Ejecuta todas las migraciones de todos los módulos.

Revertir las migraciones de un módulo:

php artisan module:migrate-rollback <module-name>

Revierte las migraciones de un módulo específico.

Correr los seeders de un módulo:

php artisan module:seed <module-name>

Ejecuta los seeders de un módulo específico para poblar la base de datos.

Ejemplo de flujo completo

Crear un nuevo módulo llamado "Blog":

php artisan module:make Blog

Generar un controlador en el módulo "Blog":

php artisan module:make-controller PostController Blog

Crear una migración para la tabla de posts en el módulo "Blog":

php artisan module:make-migration create_posts_table Blog

Generar un modelo "Post" en el módulo "Blog":

php artisan module:make-model Post Blog

Correr las migraciones de "Blog":

php artisan module:migrate Blog

Correr los seeders del módulo "Blog":

php artisan module:seed Blog
