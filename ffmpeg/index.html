Comando ffmpeg

Podemos aplicar múltiples filtros:

ffmpeg -i input.mp4 -vf "unsharp=7:7:2.0,eq=brightness=-0.12:contrast=1.43,eq=gamma_r=1.4:gamma_g=1.4:gamma_b=0.7" output.mp4
