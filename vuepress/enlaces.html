Uso de enlaces en VuePress

Para incluir enlaces externos en documentos de VuePress, podemos usar la sintaxis de Markdown:

[Texto del enlace](https://www.ejemplo.com)

Para enlazar a otras páginas dentro de un sitio VuePress, usaremos el nombre del fichero Markdown de la página (es decir, con extensión .md):

[Texto del enlace](ruta/a/la/pagina.md)

Por ejemplo, si tenemos una página llamada about.md en el mismo directorio:

[Sobre nosotros](./about.md)

También podemos enlazar directamente a un encabezado específico dentro de una página. VuePress convierte cada encabezado en un ancla:

[Ir a la sección](./about.md#seccion-especifica)
