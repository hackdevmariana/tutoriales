Avanzar al siguiente bloque en vi

Para avanzar al siguiente bloque en el editor vi, podemos usar los siguientes comandos:

Avanzar al siguiente párrafo

Presiona { para mover el cursor al inicio del párrafo anterior y } para mover el cursor al inicio del siguiente párrafo.

Avanzar al siguiente bloque de código

Si estamos trabajando con bloques de código delimitados por llaves ({}), podemos usar % para saltar entre las llaves de apertura y cierre correspondientes.

Avanzar al siguiente bloque de texto

Si los bloques están separados por líneas en blanco, podemos usar } para mover el cursor al inicio del siguiente bloque de texto.
