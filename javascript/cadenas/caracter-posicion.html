Extraer un carácter en una posición especificada de una cadena de texto

Para extraer un carácter en una posición especificada de una cadena de texto en JavaScript, tenemos el método charAt(index) que devuelve el carácter en la posición especificada.

let text = "Hola Mundo";
console.log(text.charAt(0));

Devuelve "H".
