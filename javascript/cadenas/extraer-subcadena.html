Extraer una subcadena de una cadena de texto en JavaScript

Para extraer subcadenas en JavaScript tenemos varios métodos:

slice

El método slice(start, end) extrae una sección de una cadena y devuelve una nueva cadena.

let text = "Hola Mundo";
console.log(text.slice(0, 4));

Devuelve "Hola".

substring

El método substring(start, end) es similar a slice, pero no acepta índices negativos.

let text = "Hola Mundo";
console.log(text.substring(0, 4));

Devuelve "Hola".

substr

El método substr(start, length) extrae una parte de una cadena, comenzando en el índice especificado y extendiéndose por una cantidad de caracteres dada.

let text = "Hola Mundo";
console.log(text.substr(0, 4));

Devuelve "Hola".
